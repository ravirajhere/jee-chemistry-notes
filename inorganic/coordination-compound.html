Coordination Compounds

Nomenclature, Isomerism, CFT, Magnetic Properties, EAN Rule, PYQ Analysis

1. Basic Terms

Definition

Coordination Compound: Aise compound jisme central metal atom/ion ke around ligands coordinated hote hain.

  • Double Salt → Water mein poora dissociate ho jaata hai (e.g., Mohr's salt)
  • Complex → Water mein dissociate nahi hota ya partial (e.g., [Cu(NH₃)₄]SO₄)

1.1 Important Terms

TermDefinition
Central AtomMetal atom/ion jo ligands ko hold karta hai
LigandIon/molecule jo central atom ko donate karta hai (Lewis base)
Coordination Number (CN)Central atom se attached ligand ki total donor atoms
Coordination SphereCentral atom + ligands ka group [ ] mein
Counter IonCoordination sphere ke bahar wala ion
Mains Trap

CN = number of donor atoms, not number of ligands.

[Co(en)₃]³⁺ mein CN = 6 (en bidentate, 3 × 2 = 6).

2. Classification of Ligands

2.1 Types (Denticity ke hisaab se)

TypeDonor AtomsExample
Monodentate1Cl⁻, NH₃, H₂O, CN⁻, CO
Bidentate2en, ox, acac
Tridentate3dien
Tetradentate4trien
Hexadentate6EDTA

2.2 Special Ligands

  • Ambidentate Ligand: Do different atoms se attach ho sakta hai
    • NO₂⁻ → N se (nitro), O se (nitrito)
    • SCN⁻ → S se (thiocyanato), N se (isothiocyanato)
  • Flexidentate Ligand: Denticity change kar sakta hai (EDTA → 4 ya 6)

3. Nomenclature (IUPAC)

3.1 Rules

  1. Cation pehle, anion baad mein
  2. Ligands alphabetical order mein
  3. Ligand ke naam:
    • Anionic: -ide → -ido, -ite → -ito, -ate → -ato
    • Neutral: NH₃ → ammine, H₂O → aqua, CO → carbonyl
  4. Prefixes: 2 → di, 3 → tri, 4 → tetra, 5 → penta, 6 → hexa
  5. Oxidation State: Roman numerals mein brackets mein

3.2 Examples

FormulaIUPAC Name
[Co(NH₃)₆]Cl₃Hexaamminecobalt(III) chloride
[Cu(NH₃)₄]SO₄Tetraamminecopper(II) sulphate
K₄[Fe(CN)₆]Potassium hexacyanoferrate(II)
[Pt(NH₃)₂Cl₂]Diamminedichloridoplatinum(II)
Mains Trap
  • NH₃ → ammine (double m), NH₂ → amido, NH → imido
  • H₂O → aqua, NO → nitrosyl, CO → carbonyl

4. Isomerism in Coordination Compounds

4.1 Types

TypeDefinition
StructuralDifferent connectivity
StereoisomerismSame connectivity, different arrangement

4.2 Structural Isomerism

  1. Ionisation Isomerism: [Co(NH₃)₅Br]SO₄ vs [Co(NH₃)₅SO₄]Br
  2. Hydrate Isomerism: [Cr(H₂O)₆]Cl₃ vs [Cr(H₂O)₅Cl]Cl₂·H₂O
  3. Linkage Isomerism: [Co(NH₃)₅(NO₂)]²⁺ vs [Co(NH₃)₅(ONO)]²⁺
  4. Coordination Isomerism: [Co(NH₃)₆][Cr(CN)₆] vs [Cr(NH₃)₆][Co(CN)₆]

4.3 Stereoisomerism

  • Geometrical (cis-trans):
    • Square Planar: [MA₂B₂] → cis/trans
    • Octahedral: [MA₄B₂] → cis/trans
    • Octahedral: [MA₃B₃] → fac/mer
  • Optical:
    • [M(en)₃]³⁺ → d and l forms
    • [M(en)₂Cl₂] cis → Optical + Geometrical
    • [M(en)₂Cl₂] trans → Only Geometrical
Mains Trap
  • [M(en)₃]³⁺ → Optical isomerism (d and l)
  • [M(en)₂Cl₂] → cis (optical + geometrical), trans (only geometrical)

5. Crystal Field Theory (CFT)

Basic Concept

Metal ion ke d-orbitals ligands ke electric field se split ho jaate hain.

Crystal Field Splitting Energy (Δ₀ or Δₜ): d-orbitals ke beech ka energy difference.

5.1 Splitting Patterns

GeometrySplittingOrbitals
OctahedralΔ₀t₂g (lower), e_g (higher)
TetrahedralΔₜe (lower), t₂ (higher)
Square PlanarΔd_x²-y² (highest), d_xy (lowest)

5.2 Important Points

  • Δₜ = 4/9 Δ₀ (Tetrahedral splitting is smaller)
  • Strong Field Ligands → Large Δ₀ → Low Spin
  • Weak Field Ligands → Small Δ₀ → High Spin

5.3 Spectrochemical Series

I⁻ < Br⁻ < Cl⁻ < F⁻ < OH⁻ < H₂O < NH₃ < en < NO₂⁻ < CN⁻ < CO

5.4 CFSE (Crystal Field Stabilization Energy)

CFSE (Octahedral) = [−0.4 n(t₂g) + 0.6 n(e_g)] Δ₀

Jahan n(t₂g) = t₂g mein electrons, n(e_g) = e_g mein electrons.

🧮 Numerical Example (CFSE)

Example 1: Find CFSE of [Fe(CN)₆]³⁻

  1. Fe³⁺ → d⁵
  2. CN⁻ → Strong field → Low Spin → t₂g⁵ e_g⁰
  3. CFSE = [−0.4 × 5 + 0.6 × 0] Δ₀ = −2.0 Δ₀
  4. Answer: −2.0 Δ₀
🧮 Numerical Example (CFSE)

Example 2: Find CFSE of [Fe(H₂O)₆]²⁺

  1. Fe²⁺ → d⁶
  2. H₂O → Weak field → High Spin → t₂g⁴ e_g²
  3. CFSE = [−0.4 × 4 + 0.6 × 2] Δ₀ = (−1.6 + 1.2) Δ₀ = −0.4 Δ₀
  4. Answer: −0.4 Δ₀

6. Magnetic Properties

μ = √n(n+2) BM

Jahan n = number of unpaired electrons

6.1 High Spin vs Low Spin

LigandSpinUnpaired e⁻Magnetic Moment
Weak FieldHigh SpinMoreHigh
Strong FieldLow SpinLessLow

6.2 Examples

ComplexUnpaired e⁻Magnetic MomentType
[Fe(H₂O)₆]²⁺44.90 BMHigh Spin
[Fe(CN)₆]⁴⁻00 BMLow Spin
[CoF₆]³⁻44.90 BMHigh Spin
[Co(CN)₆]³⁻00 BMLow Spin
[Ni(H₂O)₆]²⁺22.83 BMHigh Spin
[Ni(CN)₄]²⁻00 BMLow Spin
🧮 Numerical Example (Magnetic Moment)

Example: Find magnetic moment of [MnBr₄]²⁻

  1. Mn²⁺ → d⁵
  2. Br⁻ → Weak field → High Spin → 5 unpaired e⁻
  3. μ = √5(5+2) = √35 = 5.92 BM
  4. Paramagnetic

7. Colour in Coordination Compounds

Reason

d-d transition ke karan colour hota hai. Δ₀ ke hisaab se absorbed light ki wavelength change hoti hai.

  • d⁰ and d¹⁰ → Colourless (no d-d transition)
  • Ti⁴⁺ (d⁰) → Colourless
  • Zn²⁺ (d¹⁰) → Colourless
  • Cu²⁺ (d⁹) → Blue
  • Ni²⁺ (d⁸) → Green
  • Co²⁺ (d⁷) → Pink

8. Stability of Complexes

  • Higher K → More stable complex
  • Chelate Effect: Chelating ligands (bidentate, polydentate) se stability badhti hai
  • Factors: Charge on Metal ↑ → Stable, Size ↓ → Stable, Chelate Effect
Mains Trap

[Ni(en)₃]²⁺ > [Ni(NH₃)₆]²⁺ (Chelate effect)

10. EAN Rule (Effective Atomic Number)

EAN = Z − Oxidation State + 2 × CN
ComplexEAN CalculationEAN
[Co(NH₃)₆]³⁺27 − 3 + 12 = 3636 (Kr)
[Fe(CN)₆]⁴⁻26 − 2 + 12 = 3636 (Kr)
[Ni(CO)₄]28 − 0 + 8 = 3636 (Kr)
Mains Trap

EAN = 36 (Kr) most stable hota hai.

Mains Traps — Coordination Compounds

1. Coordination Number

CN = Donor atoms, not ligands.

[Co(en)₃]³⁺ → CN = 6 (en = bidentate)

EDTA → CN = 6 (hexadentate)

2. Magnetic Moment

[Ni(CN)₄]²⁻ → Diamagnetic (Square Planar)

[NiCl₄]²⁻ → Paramagnetic (Tetrahedral)

3. Hybridisation (VBT)

[Fe(CN)₆]³⁻ → d²sp³ (Inner, Low Spin)

[FeF₆]³⁻ → sp³d² (Outer, High Spin)

[Ni(CN)₄]²⁻ → dsp² (Square Planar)

4. Isomerism

[Co(en)₂Cl₂] → cis (Optical + Geometrical), trans (Only Geometrical)

[M(en)₃]³⁺ → Optical isomerism

5. Linkage Isomerism

NO₂⁻ → N se (Nitro), O se (Nitrito)

SCN⁻ → S se (Thiocyanato), N se (Isothiocyanato)

6. Spectrochemical Series

CO → Strongest field ligand

I⁻ → Weakest field ligand

Order: I⁻ < Br⁻ < Cl⁻ < F⁻ < H₂O < NH₃ < en < CN⁻ < CO

7. Colour

d⁰, d¹⁰ → Colourless (Zn²⁺, Ti⁴⁺, Sc³⁺)

Cu²⁺ → Blue, Fe³⁺ → Yellow, Ni²⁺ → Green

8. CFSE

Strong field → Low Spin → Large CFSE (negative zyada)

Weak field → High Spin → Small CFSE

9. Chelate Effect

[Ni(en)₃]²⁺ > [Ni(NH₃)₆]²⁺

10. Important Compounds

Cisplatin → Anti-cancer

Wilkinson's → Hydrogenation catalyst

Zeise's Salt → First organometallic
