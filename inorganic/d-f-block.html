d & f Block Elements

Transition Elements, Lanthanide Contraction, KMnO₄, K₂Cr₂O₇, PYQ Analysis

1. Introduction

d-Block Kya Hai?
  • Group 3 se 12 tak ke elements
  • Inka last electron d-orbital mein jaata hai
  • General configuration: (n−1)d¹⁻¹⁰ ns¹⁻²
  • Inhe Transition Elements bhi kehte hain
Transition Element Definition

Aise elements jinke atom ya stable ion mein partially filled d-orbital ho.

Zn, Cd, Hg → d¹⁰ (fully filled), isliye ye transition elements nahi hain.

f-Block Kya Hai?
  • Lanthanides (4f series) → Ce (58) se Lu (71)
  • Actinides (5f series) → Th (90) se Lr (103)
  • Inhe Inner Transition Elements kehte hain

3. General Properties

3.1 Atomic Radius

  • Across period → Decreases (Nuclear charge ↑)
  • Down group → Increases (New shell)
  • Exception: Zr ≈ Hf aur Mo ≈ W (Lanthanide contraction)

3.2 Lanthanide Contraction

  • 4f electrons poor shielding karte hain
  • Isliye Zr ≈ Hf aur Mo ≈ W ka radius almost same

3.3 Ionization Enthalpy

  • Across period → Increases
  • Down group → Decreases
  • Exception: Zn > Cu (Zn ka d¹⁰ full-filled hai)
Mains Trap
  • Mn⁺ < Cr⁺ — Mn⁺ ka 3d⁵ 4s¹, Cr⁺ ka 3d⁵ (more stable)
  • Fe²⁺ < Fe³⁺ — Fe³⁺ ka 3d⁵ half-filled, Fe²⁺ ka 3d⁶

3.4 Oxidation States

  • Common: +2, +3
  • Maximum: Mn → +7 (KMnO₄)
  • Sc → +3 only
  • Zn → +2 only
Mains Trap
  • Mn → +7 (maximum)
  • Sc → +3 (only)
  • Zn → +2 (only)
  • Fe → +2, +3 (common)

4. Important Compounds

4.1 Potassium Permanganate (KMnO₄)

  • Oxidation State of Mn → +7
  • Colour → Purple
  • Acidic medium → Mn²⁺ (colourless)
  • Neutral medium → MnO₂ (brown)
  • Basic medium → MnO₄²⁻ (green)

4.2 Potassium Dichromate (K₂Cr₂O₇)

  • Oxidation State of Cr → +6
  • Colour → Orange
  • Acidic medium → Cr³⁺ (green)
  • Structure → Two tetrahedra sharing one oxygen
Mains Trap
  • KMnO₄ → Purple, Mn = +7
  • K₂Cr₂O₇ → Orange, Cr = +6
  • Acidic medium mein KMnO₄ → Mn²⁺ (colourless)

🧮 Numerical Example (Magnetic Moment)

Example: Find magnetic moment of [MnBr₄]²⁻

  1. Mn²⁺ → d⁵
  2. Br⁻ → Weak field → High Spin → 5 unpaired e⁻
  3. μ = √5(5+2) = √35 = 5.92 BM
  4. Paramagnetic
Mains Trap
  • Mn²⁺ aur Fe³⁺ → 5 unpaired e⁻, 5.92 BM
  • Sc³⁺, Zn²⁺ → 0 unpaired, diamagnetic
  • Cu²⁺ → 1 unpaired, 1.73 BM

7. Lanthanides

7.1 General Properties

  • 4f series → Ce (58) to Lu (71)
  • Common Oxidation State → +3
  • Ce → +4 (stable, noble gas config)
  • Eu → +2 (stable, half-filled f⁷)

7.2 Lanthanide Contraction

  • 4f electrons poor shielding karte hain
  • Isliye size expected se kam hota hai
  • Result: Zr ≈ Hf, Mo ≈ W
Mains Trap
  • Ce⁴⁺ → Strong oxidising agent
  • Eu²⁺ → Reducing agent
  • Lanthanide contraction → Zr ≈ Hf

8. Actinides

  • 5f series → Th (90) to Lr (103)
  • Radioactive elements
  • Common Oxidation State → +3, +4
  • Th → +4 stable
  • U → +6 stable

Quick Revision — d & f Block Elements (Last 10 Minutes)

📐 Key Points
  • d-Block: Group 3–12, (n−1)d¹⁻¹⁰ ns¹⁻²
  • Transition Elements: Partially filled d-orbital (Zn, Cd, Hg excluded)
  • Cr: 3d⁵ 4s¹ | Cu: 3d¹⁰ 4s¹
📊 Key Orders
  • Lanthanide Contraction: Zr ≈ Hf, Mo ≈ W
  • Oxidation States: Mn (+7), Sc (+3), Zn (+2)
  • IE Exceptions: Mn⁺ < Cr⁺, Fe²⁺ < Fe³⁺
⚠️ Key Traps
  • Cr/Cu Configuration: d⁵ s¹ / d¹⁰ s¹
  • Zn, Cd, Hg → Not transition elements
  • Mn²⁺/Fe³⁺ → 5 unpaired, 5.92 BM
  • Sc³⁺, Zn²⁺ → Colourless
  • Ce⁴⁺ → Oxidising, Eu²⁺ → Reducing
🧬 Magnetic Moment
  • Formula: μ = √n(n+2) BM
  • Sc³⁺ (d⁰) → 0 BM (Dia)
  • Ti³⁺ (d¹) → 1.73 BM
  • Mn²⁺/Fe³⁺ (d⁵) → 5.92 BM
  • Cu²⁺ (d⁹) → 1.73 BM
  • Zn²⁺ (d¹⁰) → 0 BM (Dia)
🔑 KMnO₄ & K₂Cr₂O₇
  • KMnO₄ → Purple, Mn = +7
  • Acidic → Mn²⁺ (colourless)
  • Neutral → MnO₂ (brown)
  • Basic → MnO₄²⁻ (green)
  • K₂Cr₂O₇ → Orange, Cr = +6
  • Acidic + SO₂ → Cr³⁺ (green)
💡 Lanthanides & Actinides
  • Lanthanides: 4f series, +3 common, Ce⁴⁺ oxidising
  • Actinides: 5f series, Radioactive, +3/+4 common
  • Zr ≈ Hf (Lanthanide contraction)
