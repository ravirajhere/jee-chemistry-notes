3. Reactions of Aldehydes & Ketones

3.1 Nucleophilic Addition Reactions

Acetaldehyde + HCN → 2-Hydroxypropanenitrile(Cyanohydrin)
Acetaldehyde + NaHSO₃ → Sodium bisulphite adduct (White ppt)(Purification)
Grignard Reagent + Aldehyde → Secondary Alcohol(Grignard)

3.2 Oxidation Reactions

Aldehyde easily oxidises, Ketone difficult

3.3 Important Named Reactions

Acetaldehyde → Aldol (3-Hydroxybutanal)(Aldol Condensation)
Formaldehyde → Methanol + Sodium formate(Cannizzaro Reaction)
Aldehyde/Ketone → Alkane(Clemmensen Reduction)
Aldehyde/Ketone → Alkane(Wolff-Kishner Reduction)
Aldehyde + Hydroxylamine → Oxime(Oxime Formation)
Aldehyde + Hydrazine → Hydrazone(Hydrazone Formation)
Aldehyde/Ketone + 2,4-DNP → Orange/Red ppt(2,4-DNP Test)

Solved Problems — Aldehydes, Ketones & Carboxylic Acids

🧮 Problem 1: Aldol Condensation

Q: Acetaldehyde + dil. NaOH → ?

  1. Aldol Condensation
  2. 2 CH₃CHO → CH₃−CH(OH)−CH₂−CHO
  3. Answer: Aldol (3-Hydroxybutanal)
🧮 Problem 2: Cannizzaro Reaction

Q: Formaldehyde + conc. NaOH → ?

  1. Cannizzaro Reaction (no α-H)
  2. 2 HCHO → CH₃OH + HCOONa
  3. Answer: Methanol + Sodium formate
🧮 Problem 3: Clemmensen Reduction

Q: Acetone + Zn(Hg)/HCl → ?

  1. Clemmensen Reduction
  2. CH₃COCH₃ → CH₃CH₂CH₃
  3. Answer: Propane
🧮 Problem 4: Wolff-Kishner

Q: Acetaldehyde + NH₂NH₂/KOH → ?

  1. Wolff-Kishner Reduction
  2. CH₃CHO → CH₃CH₃
  3. Answer: Ethane
🧮 Problem 5: Tollens Test

Q: Which gives silver mirror with Tollens reagent?

  1. Tollens: Aldehyde only
  2. Acetaldehyde → Silver mirror
  3. Acetone → No reaction
  4. Answer: Acetaldehyde
🧮 Problem 6: Iodoform Test

Q: Which gives yellow ppt with I₂/NaOH?

  1. Iodoform: CH₃CO− or CH₃CH(OH)−
  2. Acetone (CH₃COCH₃) → Positive
  3. Acetaldehyde (CH₃CHO) → Positive
  4. Answer: Acetone & Acetaldehyde
🧮 Problem 7: HVZ Reaction

Q: Propanoic Acid + Br₂/P → ?

  1. HVZ Reaction
  2. CH₃CH₂COOH → CH₃CHBrCOOH
  3. Answer: 2-Bromopropanoic Acid
🧮 Problem 8: Decarboxylation

Q: Sodium Acetate + NaOH (CaO, Δ) → ?

  1. Decarboxylation
  2. CH₃COONa → CH₄ + Na₂CO₃
  3. Answer: Methane
🧮 Problem 9: Esterification

Q: Acetic Acid + Ethanol (H₂SO₄) → ?

  1. Esterification
  2. CH₃COOH + C₂H₅OH → CH₃COOC₂H₅
  3. Answer: Ethyl Acetate
🧮 Problem 10: NaHCO₃ Test

Q: Which gives CO₂ with NaHCO₃?

  1. Carboxylic Acid → CO₂
  2. Phenol → No reaction
  3. Alcohol → No reaction
  4. Answer: Carboxylic Acid

Quick Revision — Aldehydes, Ketones & Carboxylic Acids (Last 10 Minutes)

📐 Key Concepts

  • Cannizzaro: No α-H, conc. NaOH
  • Clemmensen: Zn(Hg)/HCl (acidic)
  • Wolff-Kishner: NH₂NH₂/KOH (basic)
  • Tollens: Aldehyde → Silver mirror
  • Iodoform: CH₃CO− or CH₃CH(OH)−
⚠️ Key Traps
  • Aldol: α-H required
  • Cannizzaro: No α-H
  • Tollens: Only Aldehyde
  • Fehling: Aliphatic aldehyde only
  • NaHCO₃: Carboxylic acid → CO₂
🔑 Named Reactions
  • Aldol: 2 CH₃CHO → Aldol
  • Cannizzaro: 2 HCHO → CH₃OH + HCOONa
  • Clemmensen: C=O → CH₂ (Zn/Hg/HCl)
  • Wolff-Kishner: C=O → CH₂ (NH₂NH₂/KOH)
  • HVZ: α-Bromination of acid
🎯 Distinction Tests
  • Tollens: Aldehyde → Silver mirror
  • Fehling: Aldehyde → Red ppt
  • Iodoform: CH₃CO− → Yellow ppt
  • NaHCO₃: −COOH → CO₂
