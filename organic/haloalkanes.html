Haloalkanes & Haloarenes

SN1, SN2, E1, E2 Mechanisms, Grignard Reagent, Haloarenes Reactions

1. Classification of Haloalkanes & Haloarenes

Haloalkanes

Alkyl halides: R−X (X = F, Cl, Br, I)

Nomenclature: Halo + alkane (e.g., Chloroethane)

Haloarenes

Aryl halides: Ar−X

Nomenclature: Halo + arene (e.g., Chlorobenzene)

TypeExampleClassification
Primary (1°)CH₃CH₂Cl−X on primary C
Secondary (2°)CH₃CHClCH₃−X on secondary C
Tertiary (3°)(CH₃)₃CCl−X on tertiary C
AllylicCH₂=CHCH₂Cl−X adjacent to C=C
BenzylicC₆H₅CH₂Cl−X adjacent to benzene
VinylicCH₂=CHCl−X on C=C
ArylC₆H₅Cl−X on benzene ring
Mains Trap

Reactivity Order:

Allylic > Benzylic > 3° > 2° > 1° > Vinylic > Aryl

Aryl aur Vinylic halides unreactive hote hain (resonance + sp² character)

2. Nucleophilic Substitution Reactions (SN)

2.1 SN1 vs SN2 Mechanism

SN1 (Racemisation) vs SN2 (Inversion)
FeatureSN1SN2
Rate LawRate = k[R−X]Rate = k[R−X][Nu⁻]
MolecularityUnimolecularBimolecular
Substrate3° > 2° > 1°1° > 2° > 3°
SolventPolar Protic (H₂O, EtOH)Polar Aprotic (DMSO, DMF)
NucleophileWeakStrong
StereochemistryRacemisationInversion (Walden)
IntermediateCarbocationTransition state
Mains Trap
  • SN1: Polar Protic solvent, 3° substrate, Racemisation
  • SN2: Polar Aprotic solvent, 1° substrate, Inversion
  • Allylic/Benzylic halides: SN1 bhi fast (resonance stabilized carbocation)

3. Elimination Reactions (E1 & E2)

E1 (Zaitsev) vs E2 (Zaitsev/Hofmann)
FeatureE1E2
Rate LawRate = k[R−X]Rate = k[R−X][Base]
Substrate3° > 2° > 1°3° > 2° > 1°
BaseWeakStrong
ProductZaitsev (more substituted)Zaitsev/Hofmann (depends on base)
Mains Trap
  • Zaitsev's Rule: More substituted alkene (more stable)
  • Hofmann Rule: Bulky base (t-BuOK) → Less substituted alkene
  • E2: Anti-periplanar geometry required

4.2 Grignard Reagent

Formation

R−X + Mg (dry ether) → R−MgX

Grignard Reagent: R−MgX

Properties: Highly reactive, moisture-sensitive

Mains Trap

Grignard Reagent Reactions:

  • + H₂O → Alkane
  • + CO₂ → Carboxylic Acid
  • + Aldehyde → Secondary Alcohol
  • + Ketone → Tertiary Alcohol

4.3 Reduction

Reduction of Haloalkanes

R−X + Zn/H⁺ → R−H

R−X + LiAlH₄ → R−H

Product: Alkane

4.4 Reaction with Metals

Wurtz Reaction

2R−X + 2Na (dry ether) → R−R + 2NaX

Limitation: Symmetrical alkanes hi bante hain

Fittig Reaction

2Ar−X + 2Na (dry ether) → Ar−Ar + 2NaX

Product: Biphenyl

4.5 Elimination Reactions

Dehydrohalogenation

R−CH₂−CH₂X + KOH (alc) → R−CH=CH₂ + KX + H₂O

Reagent: Alcoholic KOH

5. Haloarenes (Aryl Halides)

5.1 Preparation

MethodReaction
From BenzeneC₆H₆ + Cl₂ (AlCl₃) → C₆H₅Cl
SandmeyerArN₂⁺Cl⁻ + Cu₂Cl₂/HCl → ArCl + N₂
GattermannArN₂⁺Cl⁻ + Cu/HCl → ArCl + N₂

5.2 Reactions of Haloarenes

1. Nucleophilic Substitution (SNAr)

C₆H₅Cl + NaOH (623 K, 300 atm) → C₆H₅OH

Condition: High temperature & pressure

Reason: C−Cl bond strong, sp² character

2. Electrophilic Substitution

Halogens are o/p directing (but deactivating)

Reactions: Nitration, Sulphonation, Friedel-Crafts

Mains Trap
  • Haloarenes: SN1/SN2 nahi dete (C−X bond strong)
  • Haloarenes: SNAr dete hain (high T, P)
  • Halogens: o/p directing but deactivating

Solved Problems — Haloalkanes & Haloarenes

🧮 Problem 1: SN1 vs SN2

Q: Which reacts faster with NaOH: CH₃Cl or (CH₃)₃CCl?

  1. NaOH strong nucleophile hai
  2. SN2 mechanism (1° substrate)
  3. CH₃Cl (1°) → SN2 fast
  4. (CH₃)₃CCl (3°) → SN1 fast (if polar protic)
  5. Answer: CH₃Cl (SN2), (CH₃)₃CCl (SN1)
🧮 Problem 2: Zaitsev's Rule

Q: 2-Bromobutane + KOH (alc) → major product?

  1. E2 elimination
  2. Zaitsev's Rule: More substituted alkene
  3. 2-Butene (major) > 1-Butene (minor)
  4. Answer: 2-Butene (major)
🧮 Problem 3: Hofmann Product

Q: 2-Bromobutane + t-BuOK → major product?

  1. Bulky base (t-BuOK)
  2. Hofmann Rule: Less substituted alkene
  3. 1-Butene (major)
  4. Answer: 1-Butene (Hofmann)
🧮 Problem 4: Grignard Reagent

Q: CH₃MgBr + CO₂ → ?

  1. Grignard + CO₂ → Carboxylic acid
  2. CH₃MgBr + CO₂ → CH₃COOH
  3. Answer: Acetic Acid
🧮 Problem 5: Grignard + Aldehyde

Q: CH₃MgBr + HCHO → ?

  1. Grignard + Aldehyde → Secondary Alcohol
  2. HCHO (formaldehyde) → Primary Alcohol
  3. CH₃MgBr + HCHO → CH₃CH₂OH
  4. Answer: Ethanol (Primary Alcohol)
🧮 Problem 6: Wurtz Reaction

Q: CH₃Br + C₂H₅Br + Na (dry ether) → ?

  1. Wurtz Reaction mein symmetrical alkanes bante hain
  2. CH₃−CH₃, C₂H₅−C₂H₅, CH₃−C₂H₅ (mixture)
  3. Answer: Mixture of Ethane, Butane, Propane
🧮 Problem 7: Sandmeyer Reaction

Q: Benzenediazonium chloride + Cu₂Cl₂/HCl → ?

  1. Sandmeyer Reaction
  2. ArN₂⁺Cl⁻ + Cu₂Cl₂/HCl → ArCl + N₂
  3. Answer: Chlorobenzene
🧮 Problem 8: Finkelstein Reaction

Q: CH₃Cl + NaI (acetone) → ?

  1. Finkelstein Reaction
  2. R−Cl + NaI → R−I + NaCl
  3. Answer: CH₃I (Methyl Iodide)
🧮 Problem 9: SNAr

Q: Chlorobenzene + NaOH (623 K, 300 atm) → ?

  1. Haloarene + NaOH (high T, P)
  2. SNAr mechanism
  3. Answer: Phenol (C₆H₅OH)
🧮 Problem 10: Reactivity Order

Q: Arrange in decreasing order of SN2 reactivity: 1°, 2°, 3°

  1. SN2 mein steric hindrance important
  2. 1° (least hindered) > 2° > 3° (most hindered)
  3. Answer: 1° > 2° > 3°

1. HALOALKANES — PREPARATION
From Alcohols: R−OH + PCl₅ → R−Cl + POCl₃ + HCl
From Alcohols: R−OH + SOCl₂ → R−Cl + SO₂ + HCl
From Alcohols: R−OH + HX → R−X + H₂O
From Alkanes: R−H + X₂ (UV) → R−X + HX
From Alkenes: R−CH=CH₂ + HX → R−CHX−CH₃
2. NUCLEOPHILIC SUBSTITUTION
Hydrolysis: R−X + OH⁻ (aq) → R−OH
Cyanide: R−X + CN⁻ → R−CN
Ammonia: R−X + NH₃ → R−NH₂
Alkoxide: R−X + OR⁻ → R−O−R (Williamson)
Thiol: R−X + SH⁻ → R−SH
3. ELIMINATION
Dehydrohalogenation: R−CH₂−CH₂X + KOH (alc) → R−CH=CH₂
Zaitsev: More substituted alkene
Hofmann: Bulky base → Less substituted alkene
4. GRIGNARD REAGENT
Formation: R−X + Mg (dry ether) → R−MgX
+ H₂O: R−H (Alkane)
+ CO₂: R−COOH (Carboxylic Acid)
+ HCHO: R−CH₂OH (Primary Alcohol)
+ Aldehyde: R−CH(OH)−R' (Secondary Alcohol)
+ Ketone: R−C(OH)(R')−R'' (Tertiary Alcohol)
5. NAMED REACTIONS
Wurtz: 2R−X + 2Na (dry ether) → R−R + 2NaX
Wurtz-Fittig: ArX + RX + 2Na → Ar−R + 2NaX
Fittig: 2Ar−X + 2Na → Ar−Ar + 2NaX
Sandmeyer: ArN₂⁺Cl⁻ + Cu₂Cl₂/HCl → ArCl + N₂
Gattermann: ArN₂⁺Cl⁻ + Cu/HCl → ArCl + N₂
Finkelstein: R−Cl + NaI (acetone) → R−I + NaCl
Swarts: R−Cl + AgF → R−F + AgCl
Williamson: R−ONa + R'−X → R−O−R' + NaX
6. HALOARENES — PREPARATION
From Benzene: C₆H₆ + Cl₂ (AlCl₃) → C₆H₅Cl + HCl
Sandmeyer: ArN₂⁺Cl⁻ + Cu₂Cl₂ → ArCl
7. HALOARENES — REACTIONS
SNAr: C₆H₅Cl + NaOH (623 K, 300 atm) → C₆H₅OH
Nitration: Chlorobenzene + HNO₃/H₂SO₄ → o/p Nitrochlorobenzene
Friedel-Crafts: Chlorobenzene + CH₃Cl (AlCl₃) → o/p Chlorotoluene
8. REACTIVITY ORDER
SN2: 1° > 2° > 3°
SN1: 3° > 2° > 1°
Overall: Allylic > Benzylic > 3° > 2° > 1° > Vinylic > Aryl
Bond Strength: C−F > C−Cl > C−Br > C−I
