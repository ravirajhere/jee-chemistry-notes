Chemical Bonding

Ionic Bond, Lattice Energy, Fajan's Rule, VSEPR, Hybridisation, MOT

1. Ionic Bond & Lattice Energy

Ionic Bond Formation

Condition: Low IE (e⁻ donor) + High EA (e⁻ acceptor)

Stability Condition: Lattice Energy > (IE − EA)

1.1 Lattice Energy (U) – Do Definitions

Type Definition Sign
Formation 1 mole solid banne par release hone wali energy Negative (exothermic)
Dissociation 1 mole solid ko gaseous ions mein todne ki energy Positive (endothermic)
U ∝ (q₁ × q₂) / r₀, jahan r₀ = r(cation) + r(anion)

1.2 Trends

  • Charge ↑ → U ↑
  • Size ↑ → U ↓
Mains Trap

MgO > CaO > SrO > BaO (Size ↑, U ↓)

NaF < MgF₂ < AlF₃ (Charge ↑, U ↑)

2. Fajan's Rule (Polarization)

2.1 Rules

  1. Cation chota → zyada covalent
  2. Anion bada → zyada covalent
  3. Charge zyada → zyada covalent
  4. d¹⁰ configuration (Ag⁺, Zn²⁺) → zyada covalent
Priority Order (JEE Trick)

Ionic vs Covalent ka sawal aaye toh:

  1. Pehle Charge dekho
  2. Phir Size dekho
  3. Phir d¹⁰ configuration dekho

2.2 Mains Fixed Orders

  • AlF₃ < AlCl₃ < AlBr₃ < AlI₃
  • NaCl < MgCl₂ < AlCl₃
  • LiF most ionic, LiI most covalent
  • AgCl < AgBr < AgI (covalent)

3. VSEPR & Hybridisation

3.1 Steric Number (SN)

SN = σ bonds + Lone Pairs

3.2 Hybridisation Formula

H = ½ [V + M − C + A]
  • V = Valence electrons of central atom
  • M = Monovalent atoms attached
  • C = Cation charge
  • A = Anion charge
🧮 Numerical Examples (Hybridisation)

Example 1: Find hybridisation of S in SF₄

  1. V = 6 (S ke valence e⁻)
  2. M = 4 (4 F atoms)
  3. C = 0, A = 0
  4. H = ½ [6 + 4 − 0 + 0] = ½ × 10 = 5
  5. SN = 5 → sp³d → See-Saw
🧮 Numerical Examples (Hybridisation)

Example 2: Find hybridisation of Xe in XeF₄

  1. V = 8 (Xe ke valence e⁻)
  2. M = 4 (4 F atoms)
  3. C = 0, A = 0
  4. H = ½ [8 + 4 − 0 + 0] = ½ × 12 = 6
  5. SN = 6 → sp³d² → Square Planar

4. Molecular Orbital Theory (MOT)

4.1 Bond Order Formula

BO = (N_b − N_a) / 2

4.2 MOT Order

≤14 electrons (π pehle, σ baad)

σ1s, σ*1s, σ2s, σ*2s, (π2px = π2py), σ2pz, (π*2px = π*2py), σ*2pz

>14 electrons (σ pehle, π baad)

σ1s, σ*1s, σ2s, σ*2s, σ2pz, (π2px = π2py), (π*2px = π*2py), σ*2pz

🧮 Numerical Example (Bond Order)

Example: Find bond order of O₂

  1. O₂ → 16 e⁻ → >14 e⁻ → σ pehle, π baad
  2. Configuration: σ1s², σ*1s², σ2s², σ*2s², σ2pz², π2px² = π2py², π*2px¹ = π*2py¹
  3. N_b = 2 + 2 + 2 + 2 + 2 = 10
  4. N_a = 2 + 2 + 1 + 1 = 6
  5. BO = (10 − 6) / 2 = 2
  6. Unpaired e⁻ = 2 → Paramagnetic

5. Dipole Moment

μ = q × d
  • Symmetric molecule → μ = 0 (CO₂, CH₄, BF₃)
  • Asymmetric molecule → μ ≠ 0 (H₂O, NH₃, CHCl₃)
  • NH₃ (1.47 D) > NF₃ (0.24 D)

6. Back Bonding

  • Lone pair donation from filled orbital to empty orbital of adjacent atom.
  • BF₃ – B has empty p orbital, F has lone pair
  • CO – C and O both have lone pairs
  • Effect: Bond length ↓, Stability ↑
