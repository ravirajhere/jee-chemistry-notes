Chemical Thermodynamics

First Law, Enthalpy, Hess's Law, Entropy, Gibbs Free Energy, Spontaneity

1. Basic Concepts

System & Surroundings

System: The part of the universe being studied.

Surroundings: The rest of the universe that interacts with the system.

Types: Open, Closed, Isolated

1.1 State Variables

Properties that describe the state of a system (e.g., P, V, T, U, H, S).

  • State Function: Depends only on initial and final state (U, H, S, G).
  • Path Function: Depends on the path taken (q, w).

1.2 Types of Processes

ProcessConditionKey Point
IsothermalΔT = 0ΔU = 0, q = −w
Adiabaticq = 0ΔU = w
IsochoricΔV = 0w = 0, ΔU = q
IsobaricΔP = 0w = −PΔV, ΔU = q + w
ReversibleInfinite stepsMax work done
IrreversibleFinite stepsMin work done

2. First Law of Thermodynamics

ΔU = q + w
Sign Convention (IUPAC)
  • Heat absorbed by system: q = +ve
  • Heat released by system: q = −ve
  • Work done on system: w = +ve
  • Work done by system: w = −ve

2.1 Work Done (w)

w = −P_ext × ΔV

For reversible isothermal expansion of ideal gas:

w = −nRT ln(V₂/V₁) = −2.303 nRT log(P₁/P₂)

2.2 Free Expansion

  • P_ext = 0 → w = 0
  • q = 0 (adiabatic) → ΔU = 0

3. Enthalpy (H)

H = U + PV

3.1 Relationship between ΔH and ΔU

ΔH = ΔU + Δn_g RT

Where Δn_g = change in moles of gas (products − reactants).

Mains Trap
  • If Δn_g = 0 → ΔH = ΔU
  • If Δn_g > 0 → ΔH > ΔU
  • If Δn_g < 0 → ΔH < ΔU

3.2 Heat Capacity

  • C_p − C_v = R (for ideal gas)
  • C_v = f/2 R (f = degrees of freedom)
  • Monoatomic: C_v = 3/2 R, C_p = 5/2 R, γ = 1.67
  • Diatomic: C_v = 5/2 R, C_p = 7/2 R, γ = 1.4

4. Thermochemistry

4.1 Standard Enthalpy Changes

TypeDefinition
ΔH_f°Formation of 1 mole compound from elements
ΔH_c°Complete combustion of 1 mole substance
ΔH_neutralization°Formation of 1 mole water from acid + base
Bond EnthalpyEnergy to break 1 mole bonds

4.2 Hess's Law

Hess's Law

Enthalpy change is independent of the path taken. ΔH_total = sum of ΔH for individual steps.

4.3 Kirchhoff's Equation

ΔH₂ = ΔH₁ + ΔC_p (T₂ − T₁)

Where ΔC_p = C_p(products) − C_p(reactants).

5. Second Law of Thermodynamics

Statement

The entropy of an isolated system always increases over time. ΔS_universe > 0 for spontaneous process.

ΔS = q_rev / T

5.1 Entropy Changes

ProcessFormula
Phase ChangeΔS = ΔH_transition / T
Heating (Isobaric)ΔS = nC_p ln(T₂/T₁)
Heating (Isochoric)ΔS = nC_v ln(T₂/T₁)
Isothermal ExpansionΔS = nR ln(V₂/V₁)
Mains Trap

Entropy Order: Solid < Liquid < Gas

Ice → Water → Vapor: Entropy increases

6. Gibbs Free Energy (G)

ΔG = ΔH − TΔS
Spontaneity Criteria
  • ΔG < 0 → Spontaneous
  • ΔG = 0 → Equilibrium
  • ΔG > 0 → Non-spontaneous

6.1 Spontaneity Table

ΔHΔSΔG = ΔH − TΔSSpontaneity
−+Always −Spontaneous at all T
+−Always +Non-spontaneous at all T
−−− at low TSpontaneous at low T
++− at high TSpontaneous at high T

6.2 ΔG and Equilibrium Constant

ΔG° = −RT ln K = −2.303 RT log K
Mains Trap (2026 PYQ)

log K vs 1/T plot:

  • Slope = −ΔH° / 2.303R
  • Intercept = ΔS° / 2.303R

Solved Numericals — Thermodynamics

🧮 Type 1: First Law (ΔU = q + w)

Q: A gas absorbs 100 J heat and does 20 J work. Find ΔU.

  1. q = +100 J (absorbed)
  2. w = −20 J (work done by system)
  3. ΔU = q + w = 100 + (−20) = 80 J
🧮 Type 2: Isothermal Reversible Expansion

Q: 2 moles ideal gas expands isothermally at 300 K from 10 L to 20 L. Find w.

  1. w = −nRT ln(V₂/V₁)
  2. w = −2 × 8.314 × 300 × ln(20/10)
  3. w = −2 × 8.314 × 300 × 0.693
  4. w = −3457 J = −3.46 kJ

Also, ΔU = 0 (isothermal), so q = −w = +3457 J

🧮 Type 3: ΔH and ΔU Relationship

Q: For C(s) + O₂(g) → CO₂(g), ΔH = −393.5 kJ. Find ΔU at 298 K.

  1. Δn_g = moles gas products − moles gas reactants = 1 − 1 = 0
  2. ΔH = ΔU + Δn_g RT
  3. −393500 = ΔU + 0 × 8.314 × 298
  4. ΔU = −393.5 kJ (same as ΔH, since Δn_g = 0)
🧮 Type 4: Entropy Change (Phase Transition)

Q: Find ΔS for melting 1 mole ice at 0°C. (ΔH_fus = 6.01 kJ/mol)

  1. T = 0°C = 273 K
  2. ΔS = ΔH_fus / T = 6010 / 273
  3. ΔS = +22.0 J/K·mol
🧮 Type 5: Spontaneity (ΔG = ΔH − TΔS)

Q: If ΔH = +50 kJ and ΔS = +100 J/K, at what T does reaction become spontaneous?

  1. For spontaneity, ΔG < 0 → ΔH − TΔS < 0
  2. T > ΔH / ΔS = 50000 / 100
  3. T > 500 K
  4. Reaction is spontaneous above 500 K
🧮 Type 6: ΔG° and K (Equilibrium)

Q: If K = 10 at 300 K, find ΔG°.

  1. ΔG° = −2.303 RT log K
  2. ΔG° = −2.303 × 8.314 × 300 × log(10)
  3. ΔG° = −2.303 × 8.314 × 300 × 1
  4. ΔG° = −5744 J = −5.74 kJ
🧮 Type 7: Hess's Law

Q: Calculate ΔH for C(s) + ½O₂(g) → CO(g)

Given: C(s) + O₂(g) → CO₂(g), ΔH = −393.5 kJ

CO(g) + ½O₂(g) → CO₂(g), ΔH = −283.0 kJ

  1. Reverse second equation: CO₂ → CO + ½O₂, ΔH = +283.0 kJ
  2. Add: C + O₂ + CO₂ → CO₂ + CO + ½O₂
  3. Cancel common terms: C + ½O₂ → CO
  4. ΔH = −393.5 + 283.0 = −110.5 kJ
🧮 Type 8: Kirchhoff's Equation

Q: ΔH₁ = −100 kJ at 300 K, ΔC_p = 10 J/K. Find ΔH₂ at 400 K.

  1. ΔH₂ = ΔH₁ + ΔC_p (T₂ − T₁)
  2. ΔH₂ = −100000 + 10 × (400 − 300)
  3. ΔH₂ = −100000 + 1000
  4. ΔH₂ = −99 kJ
🧮 Type 9: Adiabatic Process

Q: 1 mole ideal gas (γ = 1.4) expands adiabatically from 300 K to 200 K. Find w.

  1. Adiabatic → q = 0 → ΔU = w
  2. ΔU = nC_v ΔT = 1 × (5/2 × 8.314) × (200 − 300)
  3. ΔU = 1 × 20.785 × (−100)
  4. w = ΔU = −2078.5 J = −2.08 kJ
🧮 Type 10: Bond Enthalpy

Q: Find ΔH for H₂(g) + Cl₂(g) → 2HCl(g)

Given: BE(H−H) = 436 kJ/mol, BE(Cl−Cl) = 243 kJ/mol, BE(H−Cl) = 431 kJ/mol

  1. ΔH = ΣBE(reactants) − ΣBE(products)
  2. ΔH = [436 + 243] − [2 × 431]
  3. ΔH = 679 − 862
  4. ΔH = −183 kJ

1. FIRST LAW & WORK
ΔU = q + w — First Law of Thermodynamics
w = −P_ext × ΔV — Irreversible work (constant external pressure)
w = −nRT ln(V₂/V₁) — Reversible isothermal work (volume form)
w = −2.303 nRT log(P₁/P₂) — Reversible isothermal work (pressure form)
w = 0 — Free expansion (P_ext = 0)
w = 0 — Isochoric process (ΔV = 0)
2. HEAT & HEAT CAPACITY
q = nC_p ΔT — Heat at constant pressure (isobaric)
q = nC_v ΔT — Heat at constant volume (isochoric)
C_p − C_v = R — Ideal gas
C_v = f/2 × R — Degrees of freedom (f)
C_p = (f/2 + 1) × R — Ideal gas
γ = C_p / C_v — Adiabatic index
Monoatomic: C_v = 3/2 R, C_p = 5/2 R, γ = 1.67
Diatomic: C_v = 5/2 R, C_p = 7/2 R, γ = 1.4
3. ENTHALPY
H = U + PV — Enthalpy definition
ΔH = ΔU + Δn_g RT — Relationship between ΔH and ΔU
ΔH = nC_p ΔT — Enthalpy change (ideal gas)
ΔU = nC_v ΔT — Internal energy change (ideal gas)
4. THERMOCHEMISTRY
ΔH_f° = ΣΔH_f°(products) − ΣΔH_f°(reactants) — Hess's Law
ΔH_reaction = ΣBE(reactants) − ΣBE(products) — Bond Enthalpy
ΔH₂ = ΔH₁ + ΔC_p (T₂ − T₁) — Kirchhoff's Equation
ΔH_neutralization = −57.1 kJ/mol — Strong acid + Strong base
5. ENTROPY
ΔS = q_rev / T — Entropy definition
ΔS = ΔH_transition / T — Phase change
ΔS = nC_p ln(T₂/T₁) — Heating (isobaric)
ΔS = nC_v ln(T₂/T₁) — Heating (isochoric)
ΔS = nR ln(V₂/V₁) — Isothermal expansion
ΔS = 2.303 nR log(V₂/V₁) — Isothermal expansion (log form)
ΔS_universe = ΔS_system + ΔS_surroundings
6. GIBBS FREE ENERGY
ΔG = ΔH − TΔS — Gibbs Free Energy
ΔG° = −RT ln K — Standard Gibbs Energy
ΔG° = −2.303 RT log K — Log form
ΔG = ΔG° + RT ln Q — Reaction quotient form
ΔG° = −nFE°_cell — Electrochemistry link
7. ADIABATIC PROCESS
PV^γ = constant — Adiabatic reversible
TV^(γ−1) = constant — Adiabatic
T^γ P^(1−γ) = constant — Adiabatic
q = 0, ΔU = w — Adiabatic condition
w = ΔU = nC_v ΔT — Adiabatic work
8. PROCESS SUMMARY
Isothermal: ΔT = 0 → ΔU = 0, q = −w
Adiabatic: q = 0 → ΔU = w
Isochoric: ΔV = 0 → w = 0, ΔU = q
Isobaric: ΔP = 0 → w = −PΔV, ΔU = q + w
Reversible: Infinite steps → Max work
Irreversible: Finite steps → Min work
9. SPONTANEITY TABLE
ΔH −, ΔS + → ΔG always − → Spontaneous at all T
ΔH +, ΔS − → ΔG always + → Non-spontaneous at all T
ΔH −, ΔS − → ΔG − at low T → Spontaneous at Low T
ΔH +, ΔS + → ΔG − at high T → Spontaneous at High T
