Hydrocarbons

Alkanes, Alkenes, Alkynes, Aromatic Compounds, Reaction Mechanisms

1. Alkanes (Saturated Hydrocarbons)

General Formula

CₙH₂ₙ₊₂ (n = 1, 2, 3, ...)

Hybridisation: sp³, Bond Angle: 109.5°

1.1 Preparation of Alkanes

MethodReaction
Hydrogenation of AlkenesCH₂=CH₂ + H₂ → CH₃−CH₃ (Ni, Δ)
Wurtz Reaction2R−X + 2Na → R−R + 2NaX (dry ether)
Kolbe's Electrolysis2RCOONa + 2H₂O → R−R + 2CO₂ + H₂ + 2NaOH
DecarboxylationRCOONa + NaOH (CaO, Δ) → R−H + Na₂CO₃

1.2 Reactions of Alkanes

Halogenation (Free Radical Substitution)

CH₄ + Cl₂ → CH₃Cl + HCl (UV light)

Mechanism:

  1. Initiation: Cl₂ → 2Cl• (UV)
  2. Propagation: Cl• + CH₄ → CH₃• + HCl; CH₃• + Cl₂ → CH₃Cl + Cl•
  3. Termination: Cl• + Cl• → Cl₂; CH₃• + CH₃• → C₂H₆
Alkane Halogenation — Free Radical Substitution
Mains Trap

Reactivity of Halogens: F₂ > Cl₂ > Br₂ > I₂

Selectivity: Br₂ > Cl₂ (Br• zyada selective hai)

Order of H reactivity: 3° > 2° > 1°

2. Alkenes (Unsaturated Hydrocarbons)

General Formula

CₙH₂ₙ (n ≥ 2)

Hybridisation: sp², Bond Angle: 120°

2.1 Preparation of Alkenes

MethodReaction
Dehydration of AlcoholsR−CH₂−CH₂OH → R−CH=CH₂ + H₂O (H₂SO₄, Δ)
DehydrohalogenationR−CH₂−CH₂Br + KOH (alc) → R−CH=CH₂
From AlkynesHC≡CH + H₂ → H₂C=CH₂ (Lindlar's catalyst)

2.2 Reactions of Alkenes

1. Addition of HBr (Markovnikov)

CH₃−CH=CH₂ + HBr → CH₃−CHBr−CH₃

Rule: H zyada substituted carbon par jaata hai (more stable carbocation)

Mains Trap (2026 PYQ)

Anti-Markovnikov (Peroxide Effect):

CH₃−CH=CH₂ + HBr (Peroxide) → CH₃−CH₂−CH₂Br

Sirf HBr ke saath hota hai, HCl/HI ke saath nahi

Markovnikov vs Anti-Markovnikov Addition
2. Ozonolysis

CH₃−CH=CH−CH₃ + O₃ → 2CH₃CHO (Zn/H₂O)

Reductive: Aldehyde/Ketone

Oxidative: Carboxylic Acid

3. Hydroboration-Oxidation

CH₃−CH=CH₂ + BH₃ → (CH₃−CH₂−CH₂)₃B → CH₃−CH₂−CH₂OH

Anti-Markovnikov addition of water

4. Halogenation

CH₂=CH₂ + Br₂ → CH₂Br−CH₂Br (Reddish-brown colour disappears)

Test for Unsaturation: Br₂ water decolourisation

Mains Trap

Baeyer's Reagent: Cold dilute KMnO₄ → Purple colour disappears → Test for unsaturation

Product: Vicinal diol (Glycol)

3. Alkynes (Triple Bonded)

General Formula

CₙH₂ₙ₋₂ (n ≥ 2)

Hybridisation: sp, Bond Angle: 180°

3.1 Preparation of Alkynes

MethodReaction
DehydrohalogenationCH₂Br−CH₂Br + 2KOH (alc) → HC≡CH + 2KBr
From Calcium CarbideCaC₂ + 2H₂O → HC≡CH + Ca(OH)₂

3.2 Reactions of Alkynes

1. Acidic Hydrogen

HC≡CH + Na → HC≡C⁻Na⁺ + ½H₂

Reason: sp carbon zyada electronegative hai

2. Addition of HBr

HC≡CH + HBr → CH₂=CHBr (Markovnikov)

CH₂=CHBr + HBr → CH₃−CHBr₂

3. Hydration (Kucherov)

HC≡CH + H₂O (HgSO₄/H₂SO₄) → CH₃CHO

Product: Aldehyde (terminal alkyne) ya Ketone (internal alkyne)

4. Hydroboration-Oxidation

HC≡CH + BH₃ → (CH₂=CH)₃B → CH₃CHO

Mains Trap

Terminal Alkyne: Acidic H → Sodium acetylide

Internal Alkyne: Acidic H nahi → Sodium acetylide nahi banta

Test: Ammoniacal AgNO₃ ya Cu₂Cl₂ → White/Yellow ppt (terminal alkyne)

4. Aromatic Hydrocarbons (Benzene)

Benzene (C₆H₆)

Structure: Planar hexagonal ring, sp² hybridised

Aromaticity: Huckel's Rule (4n+2)π = 6π electrons

4.1 Electrophilic Aromatic Substitution (EAS)

EAS Mechanism — Arenium Ion Intermediate

4.2 Important EAS Reactions

ReactionReagentProduct
NitrationConc. HNO₃ + Conc. H₂SO₄Nitrobenzene
SulphonationConc. H₂SO₄, ΔBenzenesulphonic acid
HalogenationCl₂/Br₂ + AlCl₃/FeBr₃Chlorobenzene/Bromobenzene
Friedel-Crafts AlkylationRCl + AlCl₃Alkylbenzene
Friedel-Crafts AcylationRCOCl + AlCl₃Ketone

4.3 Directing Effects

GroupEffectDirection
−OH, −NH₂, −OR, −RActivatingo/p directing
−NO₂, −CN, −COOH, −CHODeactivatingm directing
−Cl, −Br, −IDeactivatingo/p directing
Mains Trap

Activating groups: Electron donating → o/p directing → Rate ↑

Deactivating groups: Electron withdrawing → m directing → Rate ↓

Halogens: Deactivating but o/p directing (exception)

4.4 Reactions of Benzene

1. Addition (Under Special Conditions)

Benzene + 3H₂ → Cyclohexane (Ni, 200°C)

Benzene + 3Cl₂ → Benzene hexachloride (UV light)

2. Oxidation

Benzene + O₂ (V₂O₅, 500°C) → Maleic anhydride

Toluene + KMnO₄ → Benzoic acid

3. Side Chain Reactions

Free Radical Halogenation: Toluene + Cl₂ (UV) → Benzyl chloride

Oxidation: Toluene + KMnO₄ → Benzoic acid

Solved Problems — Hydrocarbons

🧮 Problem 1: Markovnikov Addition

Q: Propene + HBr → ?

  1. Markovnikov rule: H zyada substituted C par
  2. CH₃−CH=CH₂ + HBr → CH₃−CHBr−CH₃
  3. Answer: 2-Bromopropane
🧮 Problem 2: Anti-Markovnikov (Peroxide)

Q: Propene + HBr (Peroxide) → ?

  1. Peroxide effect: Anti-Markovnikov
  2. Br less substituted C par jaata hai
  3. CH₃−CH=CH₂ + HBr → CH₃−CH₂−CH₂Br
  4. Answer: 1-Bromopropane
🧮 Problem 3: Ozonolysis

Q: Alkene (C₄H₈) ka ozonolysis se 2CH₃CHO banta hai. Structure?

  1. Ozonolysis se C=C toot jaata hai
  2. 2CH₃CHO → CH₃−CH=CH−CH₃
  3. Answer: 2-Butene
🧮 Problem 4: Terminal Alkyne Test

Q: Which alkyne gives white ppt with ammoniacal AgNO₃?

  1. Terminal alkyne mein acidic H hota hai
  2. HC≡CH + AgNO₃/NH₄OH → AgC≡CAg (white ppt)
  3. Internal alkyne (CH₃C≡CCH₃) nahi deta
  4. Answer: Terminal alkyne (HC≡CH)
🧮 Problem 5: Kucherov Hydration

Q: HC≡CH + H₂O (HgSO₄/H₂SO₄) → ?

  1. Kucherov hydration
  2. Terminal alkyne → Aldehyde
  3. CH₃CHO
  4. Answer: Acetaldehyde (CH₃CHO)
🧮 Problem 6: EAS Directing Effect

Q: Nitrobenzene ka nitration kahan hota hai?

  1. −NO₂ deactivating aur m-directing group hai
  2. Nitration meta position par hota hai
  3. Answer: m-Dinitrobenzene
🧮 Problem 7: Friedel-Crafts

Q: Benzene + CH₃Cl (AlCl₃) → ?

  1. Friedel-Crafts Alkylation
  2. CH₃⁺ electrophile banta hai
  3. Benzene ring par attack karta hai
  4. Answer: Toluene (C₆H₅CH₃)
🧮 Problem 8: Toluene Oxidation

Q: Toluene + KMnO₄ → ?

  1. Side chain oxidation
  2. CH₃ group → COOH group
  3. Answer: Benzoic Acid (C₆H₅COOH)
🧮 Problem 9: Baeyer's Test

Q: Alkene + Cold Dilute KMnO₄ → ?

  1. Baeyer's Reagent (Cold dilute KMnO₄)
  2. Purple colour disappears
  3. Vicinal diol banta hai
  4. Answer: Glycol (Vicinal diol)
🧮 Problem 10: Wurtz Reaction

Q: CH₃Br + Na (dry ether) → ?

  1. Wurtz Reaction
  2. 2CH₃Br + 2Na → CH₃−CH₃ + 2NaBr
  3. Answer: Ethane (C₂H₆)
