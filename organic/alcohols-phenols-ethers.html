Alcohols, Phenols & Ethers

Lucas Test, Victor Meyer, Reimer-Tiemann, Kolbe, Williamson, Acidity

1. Alcohols

Classification
  • Primary (1°): −OH on primary C (RCH₂OH)
  • Secondary (2°): −OH on secondary C (R₂CHOH)
  • Tertiary (3°): −OH on tertiary C (R₃COH)

1.1 Reactions of Alcohols

1. Reaction with Active Metals

2R−OH + 2Na → 2R−ONa + H₂↑

Product: Sodium alkoxide + Hydrogen gas

2. Esterification

R−OH + R'COOH (H₂SO₄, Δ) → R'COOR + H₂O

Product: Ester (Fruity smell)

3. Dehydration

R−CH₂−CH₂OH (H₂SO₄, 443 K) → R−CH=CH₂ + H₂O

Product: Alkene

4. Oxidation

1° Alcohol + PCC → Aldehyde

1° Alcohol + KMnO₄/H⁺ → Carboxylic Acid

2° Alcohol + Jones Reagent → Ketone

3° Alcohol → No oxidation (no α-H)

Oxidation of Alcohols — 1°, 2°, 3°

2. Phenols

Structure

−OH group directly attached to benzene ring (Ar−OH)

2.1 Acidity of Phenols

Acidity of Phenols — Resonance Stabilization
Mains Trap
  • Electron Withdrawing Groups (EWG): Acidity ↑ (e.g., −NO₂, −CN, −CHO)
  • Electron Donating Groups (EDG): Acidity ↓ (e.g., −CH₃, −OCH₃)
  • o-Nitrophenol: Intramolecular H-bonding → Less acidic than p-nitrophenol

2.2 Reactions of Phenols

1. Reimer-Tiemann Reaction

Phenol + CHCl₃ + NaOH → Salicylaldehyde (o-hydroxy benzaldehyde)

Product: Ortho-substituted benzaldehyde

2. Kolbe's Reaction

Phenol + CO₂ + NaOH → Salicylic Acid (o-hydroxy benzoic acid)

Product: Ortho-substituted benzoic acid

3. Bromination

Phenol + Br₂ (aq) → 2,4,6-Tribromophenol (White ppt)

Product: Tribromophenol (Test for phenol)

4. Nitration

Phenol + dil. HNO₃ → o-Nitrophenol + p-Nitrophenol

Phenol + conc. HNO₃ → 2,4,6-Trinitrophenol (Picric acid)

5. Kolbe's Electrolysis

Phenol + Kolbe's electrolysis → Salicylic acid

2.3 Distinction Tests for Phenols

1. FeCl₃ Test

Phenol + FeCl₃ → Violet colour

Positive for: Phenols (not alcohols)

2. Bromine Water Test

Phenol + Br₂ water → White ppt (2,4,6-tribromophenol)

3. Libermann's Test

Phenol + NaNO₂/H₂SO₄ → Red colour → Blue with NaOH

3. Ethers

Structure

R−O−R' (Dialkyl ether) ya Ar−O−R (Alkyl aryl ether)

3.1 Preparation of Ethers

1. Williamson Synthesis

R−ONa + R'−X → R−O−R' + NaX

Mechanism: SN2

Limitation: 3° halide ke saath elimination (alkene) hoti hai

2. Dehydration of Alcohols

2R−OH (H₂SO₄, 413 K) → R−O−R + H₂O

3.2 Reactions of Ethers

1. Cleavage by HI

R−O−R + HI → R−I + R−OH

Mechanism: SN2 (smaller alkyl group par attack)

2. Electrophilic Substitution (Aryl Ethers)

Anisole + Br₂ (FeBr₃) → o/p-Bromoanisole

3. Zeisel's Method

Ether + HI → Alkyl iodide → AgNO₃ → AgI (Yellow ppt)

Mains Trap
  • Williamson: 1° halide best, 3° halide ke saath elimination
  • HI Cleavage: Smaller alkyl group par attack
  • Anisole: o/p directing (due to −OCH₃)

Solved Problems — Alcohols, Phenols & Ethers

🧮 Problem 1: Lucas Test

Q: Identify 1°, 2°, 3° alcohol using Lucas Test.

  1. 3° → Immediate turbidity
  2. 2° → 5 min turbidity
  3. 1° → No turbidity at room temp
  4. Answer: 3° fastest, 1° slowest
🧮 Problem 2: Victor Meyer Test

Q: Which alcohol gives red colour in Victor Meyer Test?

  1. Victor Meyer: 1° → Red, 2° → Blue, 3° → Colourless
  2. Answer: 1° Alcohol
🧮 Problem 3: Acidity of Phenols

Q: Arrange in decreasing order of acidity: Phenol, p-Nitrophenol, p-Cresol

  1. −NO₂ is EWG → Acidity ↑
  2. −CH₃ is EDG → Acidity ↓
  3. p-Nitrophenol > Phenol > p-Cresol
  4. Answer: p-Nitrophenol > Phenol > p-Cresol
🧮 Problem 4: Reimer-Tiemann

Q: Phenol + CHCl₃ + NaOH → ?

  1. Reimer-Tiemann Reaction
  2. Ortho formylation
  3. Salicylaldehyde banta hai
  4. Answer: Salicylaldehyde (o-hydroxy benzaldehyde)
🧮 Problem 5: Kolbe's Reaction

Q: Phenol + CO₂ + NaOH → ?

  1. Kolbe's Reaction
  2. Ortho carboxylation
  3. Salicylic acid banta hai
  4. Answer: Salicylic Acid (o-hydroxy benzoic acid)
🧮 Problem 6: Williamson Synthesis

Q: Sodium ethoxide + methyl iodide → ?

  1. Williamson Synthesis
  2. C₂H₅ONa + CH₃I → C₂H₅−O−CH₃ + NaI
  3. Answer: Ethyl methyl ether
🧮 Problem 7: Oxidation of Alcohols

Q: 1-Butanol + PCC → ?

  1. 1° Alcohol + PCC → Aldehyde
  2. CH₃CH₂CH₂CH₂OH + PCC → CH₃CH₂CH₂CHO
  3. Answer: Butanal
🧮 Problem 8: Iodoform Test

Q: Which gives yellow ppt with I₂/NaOH?

  1. Iodoform test: CH₃CO− or CH₃CH(OH)− group
  2. Ethanol: CH₃CH₂OH → Positive
  3. Methanol: CH₃OH → Negative
  4. Answer: Ethanol
🧮 Problem 9: FeCl₃ Test

Q: Which gives violet colour with FeCl₃?

  1. FeCl₃ test: Phenols → Violet
  2. Alcohols → No colour
  3. Answer: Phenol
🧮 Problem 10: HI Cleavage

Q: Ethyl methyl ether + HI → ?

  1. HI cleavage: Smaller alkyl group par attack
  2. Methyl (smaller) par attack → CH₃I + C₂H₅OH
  3. Answer: Methyl iodide + Ethanol
