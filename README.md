# JEE Chemistry Notes

Complete JEE Mains Chemistry Notes — Chapter-wise, PYQ Analysis (2019-2026), Mains Traps, Quick Revision, Reaction Sheets, and Diagrams.

**Live Website:** [jee-chemistry-notes.vercel.app](https://jee-chemistry-notes.vercel.app)

## 📚 Subjects

### Inorganic Chemistry (✅ 6 Chapters Ready)
- Chemical Bonding
- Periodic Table
- Coordination Compounds
- p-Block Elements
- d & f Block Elements
- Qualitative Analysis

### Physical Chemistry (✅ 8 Chapters Ready)
- Mole Concept (Some Basic Concepts)
- Thermodynamics
- Chemical & Ionic Equilibrium
- Electrochemistry
- Chemical Kinetics
- Solutions
- Atomic Structure
- Redox Reactions

### Organic Chemistry (✅ 8 Chapters Ready)
- GOC (General Organic Chemistry)
- Hydrocarbons
- Haloalkanes & Haloarenes
- Alcohols, Phenols & Ethers
- Aldehydes, Ketones & Carboxylic Acids
- Amines
- Biomolecules
- Purification & Characterisation

**Total: 22 Chapters**

## 🚀 Features

- **Chapter-wise Notes** — Structured content, easy navigation
- **PYQ Analysis (2019-2026)** — 8 years of trend data, concept-wise learning
- **Mains Traps** — Important exceptions and traps for JEE Mains
- **Solved Problems** — PYQ-based numericals and reactions
- **Quick Revision** — Summary for the last 10 minutes
- **Reaction Sheet** — All organic reactions in SVG diagram form
- **Formula Sheet** — All Physical Chemistry formulas in one place
- **Diagrams** — SVG diagrams for visual learning
- **Common + IUPAC Names** — Both names in organic reactions
- **Print / Save as PDF** — Print button in every chapter
- **Responsive Design** — Works on both mobile and desktop

## 📖 How to Use

1. **Clone the repo:**
   ```bash
   git clone https://github.com/ravirajhere/jee-chemistry-notes.git
   ```

2. **Open in browser:**
   - Open `index.html` in your browser
   - Or use the live website: [jee-chemistry-notes.vercel.app](https://jee-chemistry-notes.vercel.app)

3. **Navigate:**
   - Select a subject (Inorganic / Physical / Organic)
   - Select a chapter
   - Study using 5 tabs:
     - 📖 Theory & Diagrams
     - 🧮 Solved Problems
     - 📊 PYQ Analysis (2019-2026)
     - ⚡ Quick Revision
     - 📋 Reaction/Formula Sheet

4. **Print / Save as PDF:**
   - Every chapter has a print button
   - Useful for last-minute revision

## 🎯 JEE Mains 2026 Syllabus Coverage

These notes are made according to the **NTA JEE Main 2026 syllabus**. Deleted chapters (Polymers, Chemistry in Everyday Life, Surface Chemistry, States of Matter, s-Block, Metallurgy, Hydrogen) have not been included.

### Weightage Distribution
- **Inorganic Chemistry:** ~30%
- **Physical Chemistry:** ~35%
- **Organic Chemistry:** ~35%
