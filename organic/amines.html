2. Structure & Hybridisation

Amine Structure — Nitrogen with Lone Pair (Basic Site)
Basicity Ka Reason (Deep)

Basicity ∝ Electron density on Nitrogen

Lone pair nitrogen par hota hai. Ye lone pair jitna zyada "free" aur "electron-rich" hoga, utni basicity zyada.

  • +I effect (alkyl groups) → Electron density ↑ → Basicity ↑
  • −I effect (EWG) → Electron density ↓ → Basicity ↓
  • Resonance (aromatic amines) → Lone pair delocalized → Basicity ↓↓
  • Solvation (aqueous) → Conjugate acid stabilise → Basicity ↑
  • Steric hindrance (3° amines) → Solvation block → Basicity ↓

3. Basicity of Amines — Deep Analysis

3.1 Aqueous vs Gas Phase (PYQ Favourite)

Basicity: Aqueous (Solvation) vs Gas (Steric)
Kyun 2° > 1° > 3° (Aqueous)?
  • 2° Amine: +I effect (2 alkyl) + Solvation (1 H on N) → Best balance → Maximum basicity
  • 1° Amine: +I effect (1 alkyl) + Solvation (2 H on N) → Good, but less +I
  • 3° Amine: +I effect (3 alkyl) + No H on N → Solvation nahi hoti → Steric hindrance → Minimum basicity
  • NH₃: No +I effect, only solvation → Least basic

3.2 Aromatic Amines (Aniline) — Basicity

Aniline — Resonance Se Basicity Kam
Basicity Order: Aliphatic Amines >> Aniline

EWG (electron withdrawing) → Lone pair zyada delocalize → Basicity ↓

EDG (electron donating) → Lone pair zyada available → Basicity ↑

o-Nitroaniline: Intramolecular H-bonding + resonance → p-Nitroaniline se bhi kam basic

4. Preparation of Amines — Deep

4.1 Hofmann Bromamide Degradation

Acetamide (Ethanamide) → Methylamine (Methanamine)(Hofmann Bromamide)
Mechanism (Deep)
  1. Step 1: Br₂ + NaOH → NaOBr (Sodium hypobromite)
  2. Step 2: R−CONH₂ + NaOBr → R−CONHBr (N-Bromoamide)
  3. Step 3: R−CONHBr + NaOH → R−N=C=O (Isocyanate intermediate)
  4. Step 4: R−N=C=O + 2NaOH → R−NH₂ + Na₂CO₃

Key Point: Primary amine (1 carbon less than amide)

Mains Trap

Hofmann Bromamide: Primary amine banta hai (1 carbon less)

Example: CH₃CONH₂ → CH₃NH₂ (Acetamide → Methylamine)

Note: Aromatic amide (Benzamide) se bhi Aniline banta hai

5. Reactions of Amines — Deep

5.1 Carbylamine Test (Isocyanide Test)

Primary Amine → Isocyanide (Foul smell)(Carbylamine Test)
Deep Reasoning
  • Positive for: Only Primary amines
  • Product: Isocyanide (R−NC) — extremely foul smell
  • Why only 1°? 2° aur 3° mein H atom nahi hota CHCl₃ se react karne ke liye
  • Exception: Aromatic primary amines (Aniline) bhi positive dete hain

Kaise pucha jaata hai: "Which is most basic?"

Kaise pucha jaata hai: "Product of R−CONH₂ + Br₂/NaOH is?"

Solved Problems — Amines (Deep)

🧮 Problem 1: Basicity (Aqueous)

Q: Arrange in decreasing order of basicity (aqueous): NH₃, CH₃NH₂, (CH₃)₂NH, (CH₃)₃N

  1. 2° amine: +I (2 alkyl) + Solvation (1 H)
  2. 1° amine: +I (1 alkyl) + Solvation (2 H)
  3. 3° amine: +I (3 alkyl) + No H → No solvation
  4. NH₃: No +I, only solvation
  5. Answer: (CH₃)₂NH > CH₃NH₂ > (CH₃)₃N > NH₃
🧮 Problem 2: Basicity (Gas)

Q: Arrange in decreasing order of basicity (gas phase): NH₃, CH₃NH₂, (CH₃)₂NH, (CH₃)₃N

  1. Gas phase mein solvation nahi hoti
  2. Sirf +I effect aur steric hindrance ka balance
  3. 3° amine: Maximum +I → Most basic
  4. Answer: (CH₃)₃N > (CH₃)₂NH > CH₃NH₂ > NH₃
🧮 Problem 3: Substituted Aniline Basicity

Q: Arrange: Aniline, p-Nitroaniline, p-Toluidine, p-Chloroaniline

  1. −CH₃ = EDG → Basicity ↑
  2. −Cl = EWG (−I) → Basicity ↓ (slightly)
  3. −NO₂ = EWG (−M, −I) → Basicity ↓↓
  4. Answer: p-Toluidine > Aniline > p-Chloroaniline > p-Nitroaniline
🧮 Problem 4: Hofmann Bromamide

Q: Benzamide + Br₂/NaOH → ?

  1. Hofmann Bromamide Degradation
  2. Benzamide (C₆H₅CONH₂) → Aniline (C₆H₅NH₂)
  3. Answer: Aniline (Benzenamine)
🧮 Problem 5: Gabriel Synthesis Limitation

Q: Which amine cannot be prepared by Gabriel synthesis?

  1. Gabriel: Primary amine only
  2. Aryl halide ke saath SN2 nahi hota
  3. Answer: Aromatic Amines (Aniline)
🧮 Problem 6: Carbylamine Test

Q: Which of the following gives carbylamine test: 1°, 2°, 3° amine?

  1. Carbylamine: R−NH₂ + CHCl₃ + KOH → R−NC
  2. Only 1° amine mein 2 H atoms hote hain (reaction ke liye zaroori)
  3. Answer: Only 1° Amine
🧮 Problem 7: Hinsberg Test

Q: Which amine gives product insoluble in alkali with Hinsberg reagent?

  1. 1° → Mono-substituted (Soluble — acidic H)
  2. 2° → Di-substituted (Insoluble — no acidic H)
  3. 3° → No reaction
  4. Answer: 2° Amine
🧮 Problem 8: HNO₂ Test

Q: Which amine gives yellow oily product with HNO₂?

  1. 1° → N₂ gas
  2. 2° → N-Nitrosamine (Yellow oil)
  3. 3° → Salt (No reaction)
  4. Answer: 2° Amine
🧮 Problem 9: Diazonium Coupling

Q: Benzenediazonium chloride + Phenol/NaOH → ?

  1. Coupling Reaction
  2. ArN₂⁺ + Phenol → p-Hydroxyazobenzene
  3. Answer: Orange-red azo dye
🧮 Problem 10: Balz-Schiemann

Q: Benzenediazonium chloride + HBF₄/Δ → ?

  1. Balz-Schiemann Reaction
  2. ArN₂⁺ + HBF₄ → ArF + N₂ + BF₃
  3. Answer: Fluorobenzene
