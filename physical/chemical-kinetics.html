Chemical Kinetics

Rate Law, Order, Arrhenius Equation, Half-life, Graph Analysis

1. Rate of Reaction

Definition

Change in concentration of reactant or product per unit time.

Rate = −d[Reactant]/dt = +d[Product]/dt

1.1 Types of Rate

TypeDefinition
Average RateΔ[ ] / Δt (over a time interval)
Instantaneous Rate−d[ ] / dt (at a particular instant)
Mains Trap

Rate always positive hoti hai. Reactant ke liye negative sign lagao.

For reaction: aA + bB → cC + dD

Rate = −(1/a)d[A]/dt = −(1/b)d[B]/dt = +(1/c)d[C]/dt = +(1/d)d[D]/dt

2. Rate Law & Order

Rate Law

Rate = k [A]^x [B]^y

Jahan x, y = order with respect to A and B (experimentally determined)

Overall Order = x + y

2.1 Order vs Molecularity

OrderMolecularity
ExperimentalTheoretical
Can be zero, fractionAlways whole number (≥1)
For complex reactionsFor elementary reactions

2.2 Order from Units (JEE Shortcut)

OrderUnit of k

First Orders⁻¹

Mains Trap (2026 PYQ — 5/7 shifts)

Unit se Order detect karo:

  • k = s⁻¹ → First Order
  • k = mol L⁻¹ s⁻¹ → Zero Order
  • k = L mol⁻¹ s⁻¹ → Second Order

3. Integrated Rate Laws

3.1 Zero Order Reaction

[A] = [A]₀ − kt
k = ([A]₀ − [A]) / t
t₁/₂ = [A]₀ / 2k

Graph: [A] vs t → Straight line (slope = −k)

3.2 First Order Reaction

k = (2.303/t) log([A]₀ / [A]ₜ)
k = (2.303/t) log(a / (a−x))
t₁/₂ = 0.693 / k

Graph: log[A] vs t → Straight line (slope = −k/2.303)

3.3 Second Order Reaction

k = (1/t) × (1/[A] − 1/[A]₀)
t₁/₂ = 1 / (k [A]₀)

Graph: 1/[A] vs t → Straight line (slope = k)

Mains Trap
  • Zero Order: t₁/₂ ∝ [A]₀ (concentration par depend)
  • First Order: t₁/₂ independent of [A]₀
  • Second Order: t₁/₂ ∝ 1/[A]₀

3.4 First Order — Fractional Time (2026 PYQ)

t₁/ₙ = (2.303/k) log(n / (n−1))

Examples:

  • t₁/₂ = (2.303/k) log(2/1) = 0.693/k
  • t₁/₈ = (2.303/k) log(8/7) ≈ 0.058/k
  • t₁/₁₀ = (2.303/k) log(10/9) ≈ 0.046/k

4. Arrhenius Equation

k = A e^(−Ea/RT)
log k = log A − (Ea / 2.303RT)
log(k₂/k₁) = (Ea / 2.303R) × (1/T₁ − 1/T₂)
Graph: log k vs 1/T
  • Slope = −Ea / 2.303R
  • Intercept = log A
  • Slope negative hoga (kyunki Ea positive hai)
Mains Trap (2026 PYQ)

log k vs 1/T graph: Slope = −Ea / 2.303R

Catalyst: Ea kam karta hai, A same rehta hai

5. Graph Analysis (2026 PYQ)

PE vs Reaction Coordinate
  • Activation Energy (Ea): Reactant se transition state tak
  • ΔH: Reactant se product tak
  • Endothermic: Products ki energy zyada
  • Exothermic: Products ki energy kam
Mains Trap

3-step reaction mein slowest step = highest activation energy wala step

Overall rate = slowest step par depend

7. Methods to Determine Order

  • Initial Rate Method: Different concentrations se rate compare karo
  • Graphical Method: Straight line konse plot se aata hai
  • Half-life Method: t₁/₂ vs [A]₀ ka relation
  • Unit Method (Shortcut): k ke units se order

8. Collision Theory

Basic Idea
  • Reactant molecules collide karte hain
  • Effective collisions = high energy + proper orientation
  • Rate = P × Z × e^(−Ea/RT)
  • P = probability factor, Z = collision frequency

Solved Numericals — Chemical Kinetics

🧮 Type 1: Average Rate

Q: For N₂ + 3H₂ → 2NH₃, if Δ[NH₃] = 0.6 M in 2 min, find rate.

  1. Rate of formation of NH₃ = Δ[NH₃]/Δt = 0.6 / 120 = 0.005 M/s
  2. Rate of reaction = (1/2) × Δ[NH₃]/Δt
  3. Rate = 0.005 / 2 = 0.0025 M/s
🧮 Type 2: First Order Rate Constant

Q: A first-order reaction is 50% complete in 30 min. Find k.

  1. For 50% completion, t = t₁/₂
  2. t₁/₂ = 0.693 / k
  3. 30 = 0.693 / k
  4. k = 0.0231 min⁻¹
🧮 Type 3: First Order — Time for Specific Completion

Q: For first-order reaction, find time for 90% completion. (k = 0.01 min⁻¹)

  1. 90% complete → [A] = 0.1[A]₀
  2. k = (2.303/t) log([A]₀/[A]ₜ)
  3. 0.01 = (2.303/t) log(100/10) = (2.303/t) × 1
  4. t = 2.303 / 0.01
  5. t = 230.3 min
🧮 Type 4: First Order — Fractional Time (2026 PYQ)

Q: Find ratio t₁/₈ : t₁/₁₀ for a first-order reaction.

  1. t₁/ₙ = (2.303/k) log(n / (n−1))
  2. t₁/₈ = (2.303/k) log(8/7)
  3. t₁/₁₀ = (2.303/k) log(10/9)
  4. Ratio = log(8/7) : log(10/9) = 0.0578 : 0.0458
  5. Ratio = 1.26 : 1
🧮 Type 5: Zero Order

Q: A zero-order reaction has [A]₀ = 1 M, k = 0.01 M/s. Find time for complete reaction.

  1. [A] = [A]₀ − kt
  2. 0 = 1 − 0.01t
  3. t = 1 / 0.01
  4. t = 100 s
🧮 Type 6: Arrhenius Equation

Q: k doubles when T goes from 300 K to 310 K. Find Ea.

  1. log(k₂/k₁) = (Ea / 2.303R) × (1/T₁ − 1/T₂)
  2. log(2) = (Ea / 2.303 × 8.314) × (1/300 − 1/310)
  3. 0.301 = (Ea / 19.15) × (0.0001075)
  4. Ea = 0.301 × 19.15 / 0.0001075
  5. Ea = 53.6 kJ/mol
🧮 Type 7: Arrhenius Graph (2026 PYQ)

Q: log k vs 1/T graph has slope −5000. Find Ea.

  1. Slope = −Ea / 2.303R
  2. −5000 = −Ea / (2.303 × 8.314)
  3. Ea = 5000 × 19.15
  4. Ea = 95.7 kJ/mol
🧮 Type 8: Order from Units (2026 PYQ)

Q: If k has units mol L⁻¹ s⁻¹, what is the order?

  1. Unit formula: (mol L⁻¹)^(1−n) s⁻¹
  2. mol L⁻¹ s⁻¹ = (mol L⁻¹)^(1−n) s⁻¹
  3. 1−n = 1 → n = 0
  4. Zero Order
🧮 Type 9: Half-life (Zero vs First Order)

Q: For zero-order, t₁/₂ = 10 min at [A]₀ = 0.1 M. Find t₁/₂ at [A]₀ = 0.2 M.

  1. Zero order: t₁/₂ = [A]₀ / 2k
  2. t₁/₂ ∝ [A]₀
  3. t₁/₂(new) / t₁/₂(old) = 0.2 / 0.1 = 2
  4. t₁/₂(new) = 2 × 10 = 20 min
🧮 Type 10: Second Order

Q: For second-order reaction, [A]₀ = 0.5 M, k = 0.02 L/mol/s. Find t₁/₂.

  1. t₁/₂ = 1 / (k[A]₀)
  2. t₁/₂ = 1 / (0.02 × 0.5)
  3. t₁/₂ = 1 / 0.01
  4. t₁/₂ = 100 s
