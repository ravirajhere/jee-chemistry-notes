Redox Reactions

Oxidation Number, Balancing, Disproportionation, Redox Titration

1. Oxidation & Reduction

Classical Definition
  • Oxidation: Addition of oxygen / Removal of hydrogen
  • Reduction: Removal of oxygen / Addition of hydrogen
Electronic Definition
  • Oxidation: Loss of electrons (LEO)
  • Reduction: Gain of electrons (GER)
  • Redox: Oxidation + Reduction together

1.1 Oxidising & Reducing Agents

AgentKya karta haiExample
Oxidising AgentElectrons leta hai, khud reduce hota haiKMnO₄, K₂Cr₂O₇, Cl₂
Reducing AgentElectrons deta hai, khud oxidize hota haiH₂, CO, Zn, H₂S
Mains Trap

Oxidising agent khud reduce hota hai (electrons leta hai)

Reducing agent khud oxidize hota hai (electrons deta hai)

2. Oxidation Number (Oxidation State)

Definition

Charge jo atom ke paas hota hai agar compound ke saare bonds ionic hote.

2.1 Rules for Assigning Oxidation Number

  1. Free element → 0
  2. Monoatomic ion → Ion ka charge
  3. Oxygen → −2 (except peroxides: −1, OF₂: +2)
  4. Hydrogen → +1 (except metal hydrides: −1)
  5. Alkali metals → +1, Alkaline earth → +2
  6. Sum of oxidation numbers = Charge on species
Mains Trap
  • H₂O₂: O = −1
  • OF₂: O = +2
  • NaH: H = −1
  • KMnO₄: Mn = +7
  • K₂Cr₂O₇: Cr = +6

3. Types of Redox Reactions

TypeDefinitionExample
CombinationA + B → C2Na + Cl₂ → 2NaCl
DecompositionC → A + B2H₂O → 2H₂ + O₂
DisplacementA + BC → AC + BZn + CuSO₄ → ZnSO₄ + Cu
DisproportionationSame element oxidize + reduce2H₂O₂ → 2H₂O + O₂
ComproportionationTwo oxidation states → one2H₂S + SO₂ → 3S + 2H₂O
Mains Trap (2026 PYQ)

Disproportionation: Cl₂ + 2KOH (cold) → KCl + KClO + H₂O

  • Cl₂ (0) → Cl⁻ (−1) [Reduction]
  • Cl₂ (0) → ClO⁻ (+1) [Oxidation]

F₂ disproportionation nahi karta (F ka +1 state nahi hota)

4. Balancing Redox Reactions

Ion-Electron Method (Half-Reaction Method)
  1. Reaction ko 2 half-reactions mein todo (oxidation + reduction)
  2. Har half-reaction ko balance karo:
    • Atoms balance karo (O ke liye H₂O, H ke liye H⁺)
    • Charge balance karo (electrons add karo)
  3. Electrons equal karo (multiply karo)
  4. Dono half-reactions add karo

4.1 Acidic vs Basic Medium

MediumO balanceH balance
AcidicH₂O add karoH⁺ add karo
BasicH₂O add karoOH⁻ add karo

5. n-factor (Valency Factor)

Definition

Total number of electrons gained or lost per formula unit.

5.1 n-factor for Different Species

Speciesn-factor
AcidBasicity (H⁺ ions)
BaseAcidity (OH⁻ ions)
SaltTotal charge on cation/anion
RedoxChange in oxidation number
Mains Trap (2026 PYQ)

KMnO₄ ka n-factor:

  • Acidic medium: n = 5 (Mn⁺⁷ → Mn⁺²)
  • Neutral medium: n = 3 (Mn⁺⁷ → Mn⁺⁴)
  • Basic medium: n = 1 (Mn⁺⁷ → Mn⁺⁶)

K₂Cr₂O₇ ka n-factor: Acidic medium: n = 6 (Cr⁺⁶ → Cr⁺³)

6. Redox Titration

Concept

Redox reaction ka use karke unknown concentration nikalna.

M₁V₁ / n₁ = M₂V₂ / n₂
N₁V₁ = N₂V₂

Jahan N = Normality = Molarity × n-factor

6.1 Important Titrations

TitrationReactionn-factor
KMnO₄ vs Fe²⁺ (Mohr's salt)MnO₄⁻ + 5Fe²⁺ → Mn²⁺ + 5Fe³⁺KMnO₄ = 5, Fe²⁺ = 1
K₂Cr₂O₇ vs Fe²⁺Cr₂O₇²⁻ + 6Fe²⁺ → 2Cr³⁺ + 6Fe³⁺K₂Cr₂O₇ = 6, Fe²⁺ = 1
I₂ vs Na₂S₂O₃I₂ + 2S₂O₃²⁻ → 2I⁻ + S₄O₆²⁻I₂ = 2, Na₂S₂O₃ = 1

7. Oxidising & Reducing Power

Rule
  • Higher E°(reduction) → Stronger oxidising agent
  • Lower E°(reduction) → Stronger reducing agent

7.1 Common Oxidising Agents (Strong to Weak)

F₂ > O₃ > H₂O₂ > KMnO₄ > Cl₂ > K₂Cr₂O₇ > HNO₃ > H₂SO₄

7.2 Common Reducing Agents (Strong to Weak)

Li > K > Ca > Na > Mg > Al > Zn > Fe > H₂ > Cu

8. Electrochemical Series

Applications
  • Reactivity: Top wale metals zyada reactive
  • Displacement: Top wala metal neeche wale ko displace karta hai
  • Oxidising/Reducing Power: E° se compare karo
Mains Trap (2026 PYQ)

Strong reducing agent kaun hai?

Ans: Jiska E°(reduction) sabse kam (most negative) ho.

Solved Numericals — Redox Reactions

🧮 Type 1: Oxidation Number

Q: Find oxidation number of Mn in KMnO₄.

  1. K = +1, O = −2 (4 O atoms = −8)
  2. Sum = 0 → +1 + Mn + (−8) = 0
  3. Mn = +7
  4. Answer: +7
🧮 Type 2: Oxidation Number (Peroxide)

Q: Find oxidation number of O in H₂O₂.

  1. H = +1 (2 H atoms = +2)
  2. Sum = 0 → +2 + 2O = 0
  3. 2O = −2 → O = −1
  4. Answer: −1 (peroxide)
🧮 Type 3: Disproportionation (2026 PYQ)

Q: Cl₂ + 2KOH → KCl + KClO + H₂O. Identify oxidation and reduction.

  1. Cl₂ (0) → Cl⁻ (−1): Reduction (gain of e⁻)
  2. Cl₂ (0) → ClO⁻ (+1): Oxidation (loss of e⁻)
  3. Same element (Cl) oxidize aur reduce hua
  4. Answer: Disproportionation reaction
🧮 Type 4: n-factor (KMnO₄)

Q: Find n-factor of KMnO₄ in acidic, neutral, and basic medium.

  1. Acidic: Mn⁺⁷ → Mn⁺² → Change = 5 → n = 5
  2. Neutral: Mn⁺⁷ → Mn⁺⁴ → Change = 3 → n = 3
  3. Basic: Mn⁺⁷ → Mn⁺⁶ → Change = 1 → n = 1
🧮 Type 5: Redox Titration (Mohr's Salt)

Q: 25 mL of 0.1 M Mohr's salt requires 20 mL of KMnO₄. Find molarity of KMnO₄.

  1. Mohr's salt (Fe²⁺): n-factor = 1
  2. KMnO₄ (acidic): n-factor = 5
  3. M₁V₁/n₁ = M₂V₂/n₂
  4. 0.1 × 25 / 1 = M₂ × 20 / 5
  5. 2.5 = M₂ × 4
  6. M₂ = 0.0625 M
🧮 Type 6: Redox Titration (K₂Cr₂O₇)

Q: 20 mL of 0.1 M FeSO₄ requires 10 mL of K₂Cr₂O₇. Find molarity.

  1. FeSO₄ (Fe²⁺): n-factor = 1
  2. K₂Cr₂O₇ (acidic): n-factor = 6
  3. M₁V₁/n₁ = M₂V₂/n₂
  4. 0.1 × 20 / 1 = M₂ × 10 / 6
  5. 2 = M₂ × 1.667
  6. M₂ = 0.12 M
🧮 Type 7: Electron Transfer (2026 PYQ)

Q: I⁻ → I₂ and S²⁻ → S. Find total electrons transferred (x + y).

  1. I⁻ → I₂: 2I⁻ → I₂ + 2e⁻ → n = 1 per I⁻
  2. S²⁻ → S: S²⁻ → S + 2e⁻ → n = 2 per S²⁻
  3. Agar 2 I⁻ aur 1 S²⁻ hai: electrons = 2 + 2 = 4
  4. Answer: 4
🧮 Type 8: Balancing (Acidic Medium)

Q: Balance MnO₄⁻ + Fe²⁺ → Mn²⁺ + Fe³⁺ (acidic)

  1. Oxidation: Fe²⁺ → Fe³⁺ + e⁻
  2. Reduction: MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O
  3. Electrons equal karo (×5 oxidation)
  4. Balanced: MnO₄⁻ + 5Fe²⁺ + 8H⁺ → Mn²⁺ + 5Fe³⁺ + 4H₂O
🧮 Type 9: Balancing (Basic Medium)

Q: Balance MnO₄⁻ + I⁻ → MnO₂ + I₂ (basic)

  1. Oxidation: 2I⁻ → I₂ + 2e⁻
  2. Reduction: MnO₄⁻ + 2H₂O + 3e⁻ → MnO₂ + 4OH⁻
  3. Electrons equal karo (×2 reduction, ×3 oxidation)
  4. Balanced: 2MnO₄⁻ + 6I⁻ + 4H₂O → 2MnO₂ + 3I₂ + 8OH⁻
🧮 Type 10: Oxidising Agent Comparison

Q: Which is the strongest oxidising agent? (E°: F₂ = 2.87, Cl₂ = 1.36, Br₂ = 1.09, I₂ = 0.54)

  1. Higher E°(reduction) = Stronger oxidising agent
  2. F₂ (2.87) > Cl₂ (1.36) > Br₂ (1.09) > I₂ (0.54)
  3. Answer: F₂
