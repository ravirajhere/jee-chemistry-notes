General Organic Chemistry (GOC)

Electronic Effects, Stability, Acidity/Basicity, Isomerism

1. Electronic Effects

1.1 Inductive Effect (I)

Definition

Sigma bond ke through electron displacement, electronegativity difference ke karan.

  • −I Effect: Electron withdrawing (NO₂, CN, Cl, F, COOH)
  • +I Effect: Electron donating (CH₃, C₂H₅, alkyl groups)
−I Effect Order: −NO₂ > −CN > −COOH > −F > −Cl > −Br > −I
+I Effect Order: −C(CH₃)₃ > −CH(CH₃)₂ > −CH₂CH₃ > −CH₃

1.2 Resonance (Mesomeric Effect)

Definition

Pi electrons ka delocalization conjugated system mein.

  • +M Effect: Electron donating (−OH, −NH₂, −OR, −Cl)
  • −M Effect: Electron withdrawing (−NO₂, −CN, −CHO, −COOH)
Mains Trap

Resonance > Inductive Effect (resonance zyada strong hota hai)

−Cl mein −I aur +M dono hote hain, lekin −I zyada strong hota hai

1.3 Hyperconjugation

Definition

Sigma C−H bond ke electrons ka delocalization empty p-orbital ya pi-system ke saath.

Requirement: Alpha hydrogen (adjacent carbon par H) hona chahiye

Stability ∝ Number of alpha hydrogens (Hyperconjugation)
Mains Trap

More alpha H = More stable

CH₃−CH=CH₂ (3 αH) > CH₃−CH=CH−CH₃ (6 αH — more stable)

1.4 Electromeric Effect

Definition

Pi electrons ka complete transfer, attacking reagent ke presence mein.

Temporary effect — sirf reagent ke presence mein hota hai

2. Stability of Intermediates

2.1 Carbocation (R⁺)

Stability OrderReason
3° > 2° > 1° > CH₃⁺Hyperconjugation + Inductive effect
Benzyl > Allyl > 3°Resonance stabilisation

2.2 Carbanion (R⁻)

Stability OrderReason
CH₃⁻ > 1° > 2° > 3°Inductive effect (−I stabilizes)
sp > sp² > sp³s-character zyada = more electronegative = stable
Mains Trap (2026 PYQ)

Carbanion Stability: sp > sp² > sp³

Example: HC≡C⁻ > H₂C=CH⁻ > CH₃CH₂⁻

2.3 Free Radical (R•)

Stability: 3° > 2° > 1° > CH₃• (same as carbocation)

3. Acidity & Basicity

3.1 Acidity Order (ARIO Rule)

ARIO Rule
  • A — Atom (electronegativity)
  • R — Resonance
  • I — Inductive Effect
  • O — Orbital (hybridisation)
Acidity: Carboxylic Acid > Phenol > Water > Alcohol
Mains Trap
  • −I effect acidity badhata hai
  • +I effect acidity ghatata hai
  • Resonance stabilised anion = More acidic

3.2 Basicity Order

Aliphatic Amines: 2° > 1° > 3° > NH₃ (in aqueous solution)
In gas phase: 3° > 2° > 1° > NH₃
Mains Trap
  • +I effect basicity badhata hai
  • −I/−M effect basicity ghatata hai
  • Aromatic amines (aniline) aliphatic se kam basic

5. Aromaticity (Huckel's Rule)

Huckel's Rule

Compound aromatic hoga agar:

  1. Cyclic ho
  2. Planar ho
  3. Conjugated ho (alternate double bonds)
  4. (4n + 2) π electrons ho
Compoundπ electronsAromatic?
Benzene6✅ Aromatic
Cyclobutadiene4❌ Anti-aromatic
Cyclooctatetraene8❌ Non-planar (non-aromatic)
Naphthalene10✅ Aromatic
Pyridine6✅ Aromatic
Mains Trap
  • 4n π electrons → Anti-aromatic (if planar)
  • Non-planar → Non-aromatic
  • Cyclooctatetraene → Non-planar (tub shape), isliye non-aromatic

6. IUPAC Nomenclature

Basic Rules
  1. Longest chain identify karo
  2. Lowest locant rule follow karo
  3. Alphabetical order mein substituents likho
  4. Prefixes: di, tri, tetra (same substituent ke liye)

Solved Problems — GOC

🧮 Problem 1: Carbanion Stability (2026 PYQ)

Q: Arrange in decreasing order of stability: CH₃⁻, HC≡C⁻, H₂C=CH⁻

  1. Stability ∝ s-character (zyada s-character = zyada electronegative = stable)
  2. HC≡C⁻ → sp (50% s-character)
  3. H₂C=CH⁻ → sp² (33% s-character)
  4. CH₃⁻ → sp³ (25% s-character)
  5. Answer: HC≡C⁻ > H₂C=CH⁻ > CH₃⁻
🧮 Problem 2: Acidity Comparison

Q: Which is more acidic: Phenol or Ethanol?

  1. Phenol mein resonance stabilised phenoxide ion banta hai
  2. Ethanol mein resonance nahi hota
  3. Resonance stabilisation ke karan phenol zyada acidic
  4. Answer: Phenol > Ethanol
🧮 Problem 3: Hyperconjugation

Q: Which is more stable: 1-Butene or 2-Butene?

  1. 2-Butene mein 6 alpha hydrogens hain
  2. 1-Butene mein 3 alpha hydrogens hain
  3. More alpha H = More hyperconjugation = More stable
  4. Answer: 2-Butene > 1-Butene
🧮 Problem 4: Isomerism Counting

Q: How many structural isomers are possible for C₄H₁₀?

  1. n-Butane: CH₃−CH₂−CH₂−CH₃
  2. Isobutane: (CH₃)₃CH
  3. Answer: 2 isomers
🧮 Problem 5: Optical Isomerism

Q: How many optical isomers are possible for 2-butanol?

  1. 2-Butanol: CH₃−CH(OH)−CH₂−CH₃
  2. Chiral carbon: C2 (4 different groups: H, OH, CH₃, C₂H₅)
  3. 1 chiral carbon → 2 optical isomers (d and l)
  4. Answer: 2 optical isomers
🧮 Problem 6: Aromaticity

Q: Is cyclopentadienyl anion aromatic?

  1. Cyclic? Yes
  2. Planar? Yes
  3. Conjugated? Yes
  4. π electrons = 6 (4n + 2, n = 1)
  5. Answer: Aromatic
🧮 Problem 7: Basicity

Q: Arrange in decreasing order of basicity: NH₃, CH₃NH₂, (CH₃)₂NH, (CH₃)₃N

  1. In aqueous solution: 2° > 1° > 3° > NH₃
  2. Solvation effect aur steric hindrance ka balance
  3. Answer: (CH₃)₂NH > CH₃NH₂ > (CH₃)₃N > NH₃
🧮 Problem 8: Inductive Effect

Q: Which is more acidic: CH₃COOH or ClCH₂COOH?

  1. Cl ka −I effect hai
  2. −I effect acidity badhata hai (anion stabilize)
  3. ClCH₂COOH mein −I effect ke karan zyada acidic
  4. Answer: ClCH₂COOH > CH₃COOH
🧮 Problem 9: Carbocation Stability

Q: Arrange in decreasing order of stability: CH₃⁺, (CH₃)₃C⁺, (CH₃)₂CH⁺

  1. Hyperconjugation + Inductive effect
  2. 3° > 2° > 1° > CH₃⁺
  3. Answer: (CH₃)₃C⁺ > (CH₃)₂CH⁺ > CH₃⁺
🧮 Problem 10: Geometrical Isomerism

Q: Does 2-butene show geometrical isomerism?

  1. C=C double bond hai (restricted rotation)
  2. Same groups different sides par ho sakte hain
  3. Cis-2-butene aur Trans-2-butene possible hain
  4. Answer: Yes, cis and trans isomers
