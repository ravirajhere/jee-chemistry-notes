General Formula: Cₙ(H₂O)ₘ (Hydrates of Carbon)

3. Enzymes

Definition

Biocatalysts jo biochemical reactions ko catalyse karte hain. Proteins hote hain (except Ribozymes — RNA).

3.1 Characteristics

  • Highly specific: Lock and Key model
  • Optimum pH: Pepsin (1.5–2), Trypsin (7.5–8)
  • Optimum Temperature: 37°C
  • Denaturation: High temperature/pH se activity lost

3.2 Important Enzymes

EnzymeSubstrateProduct
AmylaseStarchMaltose
MaltaseMaltoseGlucose
LactaseLactoseGlucose + Galactose
InvertaseSucroseGlucose + Fructose
PepsinProteinsPeptides
TrypsinProteinsPeptides
Mains Trap
  • Amylase: Starch → Maltose
  • Maltase: Maltose → Glucose
  • Invertase: Sucrose → Glucose + Fructose
  • Zymase: Glucose → Ethanol + CO₂

5. Nucleic Acids

Definition

Biomolecules jo genetic information carry karte hain. Nucleotides ke polymers.

5.1 Nucleotide Components

  • Pentose Sugar: Ribose (RNA) / Deoxyribose (DNA)
  • Nitrogenous Base: Purines (A, G) / Pyrimidines (C, T, U)
  • Phosphate Group: H₃PO₄
DNA vs RNA — Differences

5.2 DNA Double Helix — Key Points

  • Watson & Crick (1953) — Double helix model
  • A = T (2 H-bonds), G ≡ C (3 H-bonds)
  • Antiparallel strands (5' → 3' and 3' → 5')
  • B-DNA: Right-handed helix
Mains Trap
  • DNA: Deoxyribose, Thymine, Double helix
  • RNA: Ribose, Uracil, Single strand
  • A=T: 2 H-bonds, G≡C: 3 H-bonds

6. Hormones

Solved Problems — Biomolecules

🧮 Problem 1: Glucose vs Fructose

Q: Differentiate glucose and fructose structurally.

  1. Glucose → Aldohexose (−CHO group)
  2. Fructose → Ketohexose (>C=O group)
  3. Both C₆H₁₂O₆ (isomers)
  4. Answer: Glucose (Aldose), Fructose (Ketose)
🧮 Problem 2: Reducing Sugars

Q: Which is a non-reducing sugar: Sucrose, Maltose, Lactose?

  1. Sucrose: Glycosidic linkage (both anomeric C)
  2. Maltose, Lactose: Free anomeric C
  3. Answer: Sucrose (Non-reducing)
🧮 Problem 3: Peptide Bond

Q: What is a peptide bond? Write its structure.

  1. Amino acids ke beech ka bond
  2. −CO−NH− linkage
  3. Condensation reaction se banta hai (H₂O nikalta hai)
  4. Answer: −CO−NH− (Amide bond)
🧮 Problem 4: Protein Structure

Q: What happens during denaturation of proteins?

  1. Secondary aur tertiary structure destroy
  2. Primary structure intact
  3. H-bonding, disulphide bonds toot jaate hain
  4. Answer: 2°/3° structure lost, 1° retained
🧮 Problem 5: Enzyme Specificity

Q: Which enzyme catalyses: Starch → Maltose?

  1. Amylase → Starch → Maltose
  2. Maltase → Maltose → Glucose
  3. Answer: Amylase
🧮 Problem 6: Vitamin Deficiency

Q: Which vitamin deficiency causes Scurvy?

  1. Scurvy → Vitamin C deficiency
  2. Ascorbic acid
  3. Answer: Vitamin C
🧮 Problem 7: Vitamin B₁₂

Q: Chemical name of Vitamin B₁₂?

  1. B₁₂ → Cyanocobalamin
  2. Contains Cobalt
  3. Answer: Cyanocobalamin
🧮 Problem 8: DNA Bases

Q: Which base is present in RNA but not in DNA?

  1. DNA: A, T, G, C
  2. RNA: A, U, G, C
  3. Answer: Uracil (U)
🧮 Problem 9: DNA H-bonds

Q: How many H-bonds are there between G and C?

  1. A=T → 2 H-bonds
  2. G≡C → 3 H-bonds
  3. Answer: 3 H-bonds
🧮 Problem 10: Insulin

Q: Which hormone is secreted by pancreas and lowers blood sugar?

  1. Insulin → Blood sugar ↓
  2. Glucagon → Blood sugar ↑
  3. Answer: Insulin
