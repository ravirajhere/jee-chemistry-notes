Chemical & Ionic Equilibrium

Kc, Kp, Le Chatelier, pH, Buffer, Ksp, Salt Hydrolysis

1. Chemical Equilibrium

Definition

Equilibrium: A state where the rate of forward reaction equals the rate of backward reaction. Concentrations become constant.

Dynamic: Reactions dono taraf chal rahi hoti hain, bas net change zero hota hai.

1.1 Law of Mass Action

For a reaction: aA + bB ⇌ cC + dD

Kc = [C]^c [D]^d / [A]^a [B]^b

Jahan [ ] = equilibrium concentrations (mol/L)

1.2 Kp and Kc Relationship

Kp = Kc (RT)^Δn

Jahan Δn = (moles of gaseous products) − (moles of gaseous reactants)

Mains Trap
  • If Δn = 0 → Kp = Kc
  • If Δn > 0 → Kp > Kc
  • If Δn < 0 → Kp < Kc

1.3 Reaction Quotient (Q)

Q vs K
  • Q < K → Forward reaction (equilibrium right shift)
  • Q > K → Backward reaction (equilibrium left shift)
  • Q = K → System at equilibrium

1.4 Le Chatelier's Principle

Principle

Agar equilibrium system par external stress daala jaaye, toh system aisa change karega jo stress ko minimize kare.

ChangeEffect on Equilibrium
Concentration ↑ (reactant)Forward shift
Concentration ↑ (product)Backward shift
Pressure ↑Shift towards fewer gas moles
Pressure ↓Shift towards more gas moles
Temperature ↑ (exothermic)Backward shift (K decreases)
Temperature ↑ (endothermic)Forward shift (K increases)
CatalystNo shift, only faster equilibrium
Mains Trap

Catalyst K ko change nahi karta — sirf equilibrium jaldi aata hai.

1.5 ICE Table Method

I = Initial concentration, C = Change, E = Equilibrium concentration

Har numerical isi method se solve hoga.

Example

H₂ + I₂ ⇌ 2HI

Initial: 1, 1, 0

Change: −x, −x, +2x

Equilibrium: 1−x, 1−x, 2x

Kc = (2x)² / (1−x)²

2. Ionic Equilibrium

2.1 Acids & Bases

Arrhenius

Acid: H⁺ deta hai. Base: OH⁻ deta hai.

Brønsted-Lowry

Acid: Proton (H⁺) deta hai. Base: Proton leta hai.

Lewis

Acid: Electron pair leta hai. Base: Electron pair deta hai.

2.2 pH, pOH, and Kw

pH = −log[H⁺], pOH = −log[OH⁻]
pH + pOH = 14 (at 25°C)
Kw = [H⁺][OH⁻] = 10⁻¹⁴

2.3 Weak Acid and Base

Ka = [H⁺][A⁻] / [HA]
Kb = [BH⁺][OH⁻] / [B]
Ka × Kb = Kw
Ostwald's Dilution Law

For weak acid: [H⁺] = √(Ka × C)

α = √(Ka / C)

2.4 Buffer Solutions

Buffer

Solution jo pH change ko resist karta hai. Do types:

  • Acidic Buffer: Weak acid + Salt (CH₃COOH + CH₃COONa)
  • Basic Buffer: Weak base + Salt (NH₄OH + NH₄Cl)
pH = pKa + log([Salt] / [Acid])

(Henderson-Hasselbalch Equation)

Mains Trap

Buffer capacity maximum hoti hai jab [Salt] = [Acid], matlab pH = pKa.

2.5 Salt Hydrolysis

Salt TypeNaturepH
Strong Acid + Strong BaseNeutralpH = 7
Weak Acid + Strong BaseBasicpH > 7
Strong Acid + Weak BaseAcidicpH < 7
Weak Acid + Weak BaseDepends on Ka/KbpH ≈ 7 (if Ka = Kb)

2.6 Solubility Product (Ksp)

For AₓBᵧ: Ksp = [A⁺]ˣ [B⁻]ʸ
Common Ion Effect

Common ion add karne se solubility decrease hoti hai.

Mains Trap
  • Q < Ksp → No precipitate (unsaturated)
  • Q > Ksp → Precipitate forms (supersaturated)
  • Q = Ksp → Saturated solution

2.7 Salt Hydrolysis Formulas

Salt TypepH Formula
Weak Acid + Strong BasepH = 7 + ½(pKa + log C)
Strong Acid + Weak BasepH = 7 − ½(pKb + log C)
Weak Acid + Weak BasepH = 7 + ½(pKa − pKb)

Solved Numericals — Equilibrium

🧮 Type 1: Kc Calculation (ICE Table)

Q: For H₂ + I₂ ⇌ 2HI, initial [H₂] = [I₂] = 1 M, at equilibrium [HI] = 1.5 M. Find Kc.

  1. ICE Table: H₂ + I₂ ⇌ 2HI
  2. Initial: 1, 1, 0
  3. Change: −x, −x, +2x
  4. Equilibrium: 1−x, 1−x, 2x
  5. 2x = 1.5 → x = 0.75
  6. [H₂] = 0.25, [I₂] = 0.25, [HI] = 1.5
  7. Kc = (1.5)² / (0.25 × 0.25) = 2.25 / 0.0625 = 36
🧮 Type 2: Kp and Kc Relationship

Q: For N₂ + 3H₂ ⇌ 2NH₃, Kc = 0.5 at 400 K. Find Kp.

  1. Δn = moles gas products − moles gas reactants = 2 − 4 = −2
  2. Kp = Kc (RT)^Δn
  3. Kp = 0.5 × (0.0821 × 400)^(−2)
  4. Kp = 0.5 / (32.84)² = 0.5 / 1078.5
  5. Kp = 4.63 × 10⁻⁴
🧮 Type 3: pH of Weak Acid

Q: Find pH of 0.1 M CH₃COOH (Ka = 1.8 × 10⁻⁵)

  1. [H⁺] = √(Ka × C)
  2. [H⁺] = √(1.8 × 10⁻⁵ × 0.1) = √(1.8 × 10⁻⁶)
  3. [H⁺] = 1.34 × 10⁻³
  4. pH = −log(1.34 × 10⁻³) = 3 − log(1.34)
  5. pH = 2.87
🧮 Type 4: Buffer pH (Henderson Equation)

Q: Find pH of buffer with 0.1 M CH₃COOH and 0.2 M CH₃COONa (pKa = 4.74)

  1. pH = pKa + log([Salt] / [Acid])
  2. pH = 4.74 + log(0.2 / 0.1)
  3. pH = 4.74 + log(2)
  4. pH = 4.74 + 0.301
  5. pH = 5.04
🧮 Type 5: Ksp and Solubility

Q: Ksp of AgCl = 1.8 × 10⁻¹⁰. Find solubility.

  1. AgCl ⇌ Ag⁺ + Cl⁻
  2. Ksp = s × s = s²
  3. s = √Ksp = √(1.8 × 10⁻¹⁰)
  4. s = 1.34 × 10⁻⁵ M
🧮 Type 6: Common Ion Effect

Q: Find solubility of AgCl in 0.1 M NaCl (Ksp = 1.8 × 10⁻¹⁰)

  1. AgCl ⇌ Ag⁺ + Cl⁻
  2. [Cl⁻] = 0.1 (from NaCl)
  3. Ksp = [Ag⁺][Cl⁻] = s × 0.1
  4. s = Ksp / 0.1 = 1.8 × 10⁻¹⁰ / 0.1
  5. s = 1.8 × 10⁻⁹ M
  6. (Solubility decreased from 1.34 × 10⁻⁵ to 1.8 × 10⁻⁹)
🧮 Type 7: Salt Hydrolysis pH

Q: Find pH of 0.1 M CH₃COONa (Ka = 1.8 × 10⁻⁵)

  1. Weak Acid + Strong Base → Basic salt
  2. pH = 7 + ½(pKa + log C)
  3. pKa = −log(1.8 × 10⁻⁵) = 4.74
  4. pH = 7 + ½(4.74 + log 0.1)
  5. pH = 7 + ½(4.74 − 1)
  6. pH = 7 + 1.87 = 8.87
🧮 Type 8: Kp and Q (Reaction Direction)

Q: For a reaction, Kp = 10, Q = 5. Direction of reaction?

  1. Q < K
  2. Forward reaction favoured
  3. Equilibrium shifts right
🧮 Type 9: Ostwald's Dilution Law

Q: Find α of 0.01 M CH₃COOH (Ka = 1.8 × 10⁻⁵)

  1. α = √(Ka / C)
  2. α = √(1.8 × 10⁻⁵ / 0.01)
  3. α = √(1.8 × 10⁻³) = 0.0424
  4. α = 4.24%
🧮 Type 10: pH of Strong Acid

Q: Find pH of 0.001 M HCl

  1. HCl → H⁺ + Cl⁻ (complete dissociation)
  2. [H⁺] = 0.001 = 10⁻³
  3. pH = −log(10⁻³) = 3
